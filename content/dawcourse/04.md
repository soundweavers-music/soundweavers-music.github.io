## 兩種軌道，兩種「聲音的來源」

| | 音訊軌（波形） | MIDI 軌（♪） |
|---|---|---|
| 裡面存什麼 | 已經錄好、匯入的聲音 | 音符：音高、時間、長度、力度 |
| 換音色 | 不行（聲音已經定型） | 可以，隨時換 |
| 改速度 | 會伸縮（時間伸縮） | 跟著小節走，最自然 |
| 改音高 | 要重新算（片段升起音） | 直接改音符 |
| 典型用途 | 人聲、木吉他、實錄鼓 | 鋼琴、弦樂、合成器、鼓機 |

一句話：**音訊軌是「結果」，MIDI 軌是「指令」**。指令可以換樂器重演，結果只能加工。

## 軌道標頭上的按鈕

- **M（靜音）**：這條軌不發聲。
- **S（獨奏）**：只聽有按 S 的軌（可以多條）。注意獨奏是「全域」的，會影響其他軌。
- **R（待命）**：告訴軟體「錄音要錄進這一條」。音訊軌按 R 還要開 **I（輸入監聽）** 才聽得到自己的聲音。
- **推桿**：這一軌的音量（dB）。
- **色塊**：點一下換顏色，方便在幾十軌裡認人。

## 原理：推桿的 0 dB 不是「最大聲」

推桿上的 `0.0` 是**參考點**，不是上限。往上推會變大聲，往下是衰減。真正決定「會不會爆」的是所有軌加起來之後的總和：

- 40 條軌都推到 0 dB，主輸出一定爆。
- 專業做法是每條軌留空間（人聲大約 −6 dB 尖峰），讓母帶有東西可以處理。

dB 是對數單位：**+6 dB 約等於兩倍振幅**，−6 dB 約等於一半。所以「只推一點點」常常就已經很大聲了。

## 原理：聲像（Pan）

左右位置是用「等功率」方式分配：放在中間時，左右各得到約 −3 dB，而不是各一半。這樣從中間移到左邊時，**總音量聽起來才不會忽大忽小**。
