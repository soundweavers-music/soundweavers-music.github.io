# 人聲與歌唱 — 改寫規格

這 50 章是給「想學會唱歌的一般人」看的，不是給聲樂系看的。改寫時先讀完這份。

## 三件事

1. **像有人在旁邊教你說話一樣的語氣。** 用「你」稱呼讀者，用短句，用日常例子。
   不要用「本文將闡述」「接下來我們要進入……的領域」這種講義腔。
2. **每一段都要有「所以呢」。** 講完一個概念，要能回答：讀者下次唱歌時，具體要改哪個動作？
3. **生理與聲學講對，比喻才站得住。** 比喻可以誇張，事實不行。凡是牽涉
   肌肉名稱、頻率、音域、時間的具體數字，都要能對得上聲樂教學與聲學的通行說法。

## 語氣對照

| 不要這樣寫 | 改成這樣 |
|---|---|
| 這堂 45 分鐘的課程，我們將帶你揭開……的面紗 | 接下來十分鐘，我們要搞懂一件事：…… |
| 這是一個註定會讓聲帶受傷的錯誤觀念 | 這樣唱，聲帶真的會受傷 |
| 你將迎來歌唱生涯中最大的一次突破 | （直接講這個練習做完會發生什麼） |
| 讓我們回到在第 5 章曾稍微提過的「木吉他」比喻 | 還記得第 5 章那個木吉他嗎 |
| 完美、極致、神聖領域、終極、震撼人心 | 刪掉。用具體結果取代：「原本唱不上去的那個音會變鬆」 |
| 45 分鐘的課程、本堂課預計…… | 刪掉時長承諾。改成「這一段大概練十次」這種可執行的量 |

## 硬性規則

1. **繁體中文，台灣用語。**「麥克風」「音準」「咬字」「丹田」這些照用，不要改成大陸用語。
2. **不確定的事實不要寫。** 特別是：
   - 具體百分比（「CT 佔 90%」）——除非那是教學上的粗分，說清楚「這只是記法」。
   - 具體頻率、音域數字——要與通行資料一致（例如男聲基頻約 100–150 Hz、
     女聲約 200–250 Hz；人聲主要能量在 1–4 kHz 附近）。
   - 肌肉名稱與作用要對：甲杓肌（TA）讓聲帶變厚變短、音變低；
     環甲肌（CT）拉長拉薄、音變高。不要寫反。
   - 不要編造歌手名字、曲名、研究文獻。
3. **不要行銷語與空話。** 禁用：完美、極致、神級、終極、震撼、靈魂的洗禮、
   千里之行始於足下、眾所周知、據說、一般認為。
4. **不要萬用開場。** 不准用「歡迎來到……課程」「在我們共同走過的前 N 章」開頭。
   第一句就要是具體的事。
5. **練習步驟必須可執行。** 每一章至少有一個「現在就做」的段落，寫明：
   發什麼音、多高、多久、幾次、做完身體應該有什麼感覺、做錯會怎樣。

## 固定結構

保留原有的分節順序概念，但標題改成口語：

```markdown
## 先講結論

（3–5 句。這一章解決什麼問題、練完會有什麼改變。不要鋪陳。）

## 常見誤解

（1–2 個。用「很多人以為……其實……」的寫法，不要用引言區塊。）

## 原理：為什麼會這樣

（把機制講清楚。比喻可以用，但要指出比喻在哪裡會失真。）

## 打個比方

（2–3 個比喻。每個比喻都要能對回機制，不能只是好聽。見下方規則。）

## 現在就做

（逐步練習。編號清單。每一步都要有「感覺」與「做錯會怎樣」。）

## 練完之後

（做對了會怎樣；常見卡點；下一步接哪一章。）

## 延伸查證

（3–4 條可查證的來源。見下方規則。）
```

章節長度：中文 1,400–2,200 字。比原稿短，因為原稿有大量形容詞與重複；
但加了比喻與查證之後會比上一版長一點，這是預期的。少於 1,200 字就是沒寫完整，
超過 2,400 字就是又開始囉嗦了。

## 比喻要怎麼寫

一個好的比喻要滿足三件事：**具體、可操作、對得回機制**。

- 具體：講得出畫面。「像換檔」比「像轉換狀態」好。
- 可操作：讀者能拿它去調整動作。例如「踩到一半的離合器」直接對應「先鬆閉合再補氣」。
- 對得回機制：比喻結束要能指回真實構造（「同一條聲帶，換的是用力比例」）。
  只寫比喻、不寫對應，就是耍花腔。

禁止「像天鵝絨般柔滑」這種純形容詞比喻。要用就用生活裡會發生的事：
換檔、吹蠟燭、踩離合器、甩繩子、水管口徑、橡皮筋、泛音。

## 延伸查證要怎麼寫

目的：讀者可以自己查，而且查得到。

- 每章 3–4 條。優先順序：同儕審查論文 → 教科書 → 官方衛教（ASHA、NIDCD 等）。
- 每條要寫：作者、年份、標題、期刊、卷期頁（若有）、**PubMed PMID 或 DOI**。
- 數字型的主張（壓力、頻率、比例、時間）在正文用括號標來源，例如（Titze, 2006）。
- **不准編造文獻。** 寫之前先用 PubMed E-utilities 查一次，把 PMID 抄進來：
  `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi?db=pubmed&retmode=json&term=...`
  再把 id 丟進 `esummary.fcgi` 核對標題、期刊、年份。
- 查不到就換一條，或改成教科書；寧可少一條，不要假一條。

## 示意圖要怎麼做

圖**不要手寫**。全部由 `scripts/build_vocal_figures.py` 產生：

```bash
python scripts/build_vocal_figures.py            # 重畫全部
python scripts/build_vocal_figures.py hum mix    # 只重畫指定幾張
```

- 共用一套視覺規範（畫布、字級、線寬、色票、標註），新增圖只要在 `FIGURES`
  註冊表加一筆，回傳 `(寬, 高, 標題, 副標, 內文, 註腳)`。
- 產生器會用文字方塊估算檢查標籤重疊，有問題會在建置時警告。
- 解剖構造一律畫成**示意圖**（色塊、剖面、標籤），不要嘗試擬真插畫。
- 引用方式不變：`![替代文字](../../assets/vocal/檔名.svg)`。

- 只在「這件事用畫的比用說的快」時放圖：聲道路徑、聲帶開合、共鳴位置、
  音域與換聲區、麥克風距離。純情緒性的插圖不要。
- 同一張圖若多章適用，就重複引用，不要每章各畫一張。
