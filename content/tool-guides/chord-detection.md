# 自動抓和弦　使用說明

## 這個工具在做什麼

上傳一段音樂，工具會分析節拍與和弦，把結果排成「簡譜式小節表格」：每個小節對應到一組和弦，可以逐拍微調、移調、標示 Capo，還能匯入歌詞。

所有分析都在你的瀏覽器裡執行，**音檔不會上傳到任何伺服器**。

## 第一步：上傳音檔

把 mp3、wav、m4a 等音檔拖進來或點選上傳。建議：

- 用乾淨的混音（人聲＋伴奏）比現場錄音準。
- 太長的檔案可以先切出你要分析的那一段。
- 檔案越大，第一次分析越久，這是正常的。

## 第二步：確認樂器與調弦

分析前先告訴工具「這是什麼樂器、用什麼調弦」，它才知道每個和弦在指版上該長什麼樣子：

- **樂器**：吉他、烏克麗麗等。
- **調弦**：標準調弦或你實際用的調弦（例如 Drop D）。
- **把位**：選「自動」會用最省力的按法；選「只用 C／G 指型」則限制在初學者熟悉的兩個封閉把位，彈起來簡單但和弦名稱可能不是唯一解。

## 第三步：校正節拍

拍點抓錯，和弦就會對錯小節，所以先校正節拍再看和弦：

| 控制 | 用途 |
|---|---|
| 拍號 4/4、3/4 | 這首歌的拍號 |
| 預備拍 | 樂器從第幾拍開始，前面幾拍是預備拍 |
| BPM | 顯示目前估到的速度，可手動微調 |
| ◀ 拍 / 拍 ▶ | 整首歌往前／往後移動一拍 |
| ◀ ½ / ½ ▶ | 移動半拍，處理切分音或提前進來的和弦 |
| −20ms / ＋20ms | 極細的時間補償，讓格線貼齊鼓點 |

右邊的 ▶ 可以播放，邊聽邊調最快。改完按「套用」把校正結果套回整份分析。

## 第四步：讀懂表格

- **和弦名**：預設顯示和弦名稱（C、G、Am…）。
- **級數**：切換成這個調的級數（1、5、6m…）。抓歌時看級數比看和弦名更容易發現「這兩段其實一樣」。
- 點小節可以試聽該段，確認抓到的是不是你耳朵聽到的。
- 表格右側可以**移調**、標示 **Capo**（實際按的位置和聽起來的音分開標）。

## 第五步：加歌詞與匯出

歌詞可以貼在「歌詞」欄位，會對齊到小節；也可以直接匯入 .lrc 檔。

完成後可以匯出文字或 Word：匯出的是和弦＋歌詞排好的簡譜，直接拿去練習或給學生都可以。

## 準確度到哪裡

工具用的是訊號分析加常見進行的先驗，對流行歌、民謠、教會詩歌這類和聲清楚的曲子準確度較好；以下情況請當成「初稿」，自己再修：

- 大量刷奏失真、和弦被鼓聲蓋掉
- 爵士、調式互換頻繁的曲子
- 只有鋼琴或只有人聲的錄音

修的方式就是上面那幾個按鈕：先把節拍對齊，再逐小節改和弦名稱。

## 常見問題

**可以處理影片嗎？**
不行，請先把音軌抽出來（用 [LRC 動態歌詞工作室](/tools/lrc/) 之外的工具或剪輯軟體）。

**分析結果跟我彈的聽起來不一樣？**
先看 Capo 與移調設定是否正確，再看「把位」是不是被限制住了。

**檔案會不會被存下來？**
不會。頁面沒有任何連外的分析請求，關掉分頁資料就沒了。
