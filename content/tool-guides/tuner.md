# 線上調音器與節拍器　使用說明

## 這個工具在做什麼

左邊是調音器，右邊是節拍器。調音器用麥克風聽你彈的音，即時算出音高，換算成「差幾個音分（cent）」；節拍器負責打拍子。

麥克風收到的聲音只在你自己的瀏覽器裡分析，不會上傳。這個頁面的安全政策也不允許它連到任何外面的伺服器。

## 第一步：給麥克風權限

按 **「開始聽音」**，瀏覽器會問可不可以收音，選「允許」。沒看到提示的話，看一下網址列左邊的鎖頭圖示，把麥克風改成允許再按一次。

如果你有兩個以上的麥克風（筆電內建、USB 麥克風、錄音介面），在「輸入裝置」選一個。開始聽音之後才會出現裝置名稱。

## 第二步：選樂器

「樂器」選單裡有 15 種常見調弦：

| 類別 | 樂器 |
|---|---|
| 撥弦 | 吉他 EADGBE、烏克麗麗 GCEA（高音／低音 G）、電貝斯 4 弦／5 弦、曼陀林、五弦班卓琴 |
| 擦弦 | 小提琴、中提琴、大提琴、低音提琴、二胡 |
| 其他 | 琵琶 ADEA、中阮 GDGD、三味線（本調子） |

選好之後，下方會出現這個樂器的空弦。**點一下任何一條弦就會播參考音**，可以先用耳朵聽、再對麥克風調。

選「自動辨識（單音）」就不分樂器，任何一個音都會直接顯示最近的音名與偏差，適合調音器以外的場合（例如檢查某個音有沒有吹準）。

## 第三步：看刻度盤

- **中間綠色的區域**是 ±5 音分，指針停在裡面就算準了。
- 數字顯示的是 **cent（音分）**：100 音分＝一個半音。+10 表示高了 0.1 個半音。
- 指標顏色：綠色（±5 以內）、黃色（±15 以內）、紅色（更多）。
- 弦的按鈕會跟著亮起來，告訴你現在接近哪一條弦。

調弦方向的口訣：**偏低就轉緊（拉高），偏高就放鬆（拉低）**，一次轉一點點，指標會慢慢往中間靠。

弦樂器剛換弦、或吉他放很久沒彈，會需要反覆調兩三輪：先全部調到接近，再從低音弦調一次，因為調後面的弦會改變琴頸的張力。

## 參考音 A4

管弦樂團常把 A4 定在 442 Hz，有些古樂演奏用 415 Hz，也有人偏好 432 Hz。改這個數字，所有目標頻率會跟著換算，刻度盤不變。

| 常見設定 | 用途 |
|---|---|
| 440 Hz | 國際標準，大部分流行音樂與練習用 |
| 442 Hz | 歐洲樂團、部分管弦樂團 |
| 415 Hz | 巴洛克古樂 |
| 432 Hz | 個人偏好 |

## 節拍器

| 控制 | 說明 |
|---|---|
| BPM | 30–260。拉滑桿或按 **Tap** 連點幾下量速度 |
| 拍號 | 決定一小節有幾拍、第一拍在哪裡 |
| 細分 | 一拍打一下、對半（八分）、三連音、四等分（十六分） |
| 音色 | 木魚、電子嗶、低鼓 |
| 第一拍重音 | 每小節第一拍用不同音高，聽得出小節線 |
| 只閃燈不出聲 | 錄音時想看到拍子但不要收到節拍聲 |

BPM 指的是「拍號下方那個音符」的速度：4/4 時是四分音符，6/8、9/8 時是八分音符。所以 6/8 的 120 BPM，一小節是 6 個八分音符、共 1.5 秒。

**重要**：用喇叭播節拍器時，麥克風會一起收到節拍聲，調音器就會顯示節拍器的音高。要同時用，請戴耳機。

## 常見問題

**指標一直跳，抓不到音**

聲音太小或太雜。靠近麥克風一點，一次只彈一個音（不要刷和弦），讓音自然延續一兩秒。背景有冷氣、風扇、電視都會干擾。

**低音弦（貝斯、大提琴 C 弦）反應比較慢**

低音的波長長，程式需要收集足夠長的時間才判得出來，慢半拍是正常的，等它穩定再讀數字。

**音聽起來明明一樣，卻顯示差了十幾音分**

先確認參考音對不對（A4 是不是被改過），再看是不是抓到高八度或低八度的泛音。換一條弦重新撥一次通常就恢復。

**手機上可以用嗎**

可以，但要用有麥克風權限的瀏覽器（Chrome、Safari、Edge），而且要在 https 或 localhost 下才會開放麥克風。
