# LRC 動態歌詞工作室　使用說明

## 這個工具在做什麼

把一首歌與一份歌詞，變成播放器看得懂的動態歌詞檔（`.lrc`）或字幕檔（`.srt`）。

做法很單純：音檔在瀏覽器裡播放，你邊聽邊按 Enter 標記「這一句從這裡開始」，時間碼自動寫進去。工具也會先幫你偵測句與句之間的停頓，把初稿排好，你只需要修。

音檔與歌詞都留在你的電腦上，不會上傳。

## 第一步：放進音檔與歌詞

1. 選一個音檔（mp3、wav、m4a 皆可）。
2. 把歌詞貼進「歌詞」欄位，一行一句。

歌詞格式沒有特別要求，一行就是一句；如果原本是分段落的歌詞，把空行刪掉會比較好對。

## 第二步：先讓工具排初稿

按 **「偵測並填入時間」**，工具會依音量變化找出「句與句之間的停頓」，先把時間碼填好。這一步不要求準，只是省掉你從零開始敲。

兩個參數可以調：

| 參數 | 作用 |
|---|---|
| 靈敏度 | 越高越容易切成一句。伴奏很滿、人聲不明顯時往下調 |
| 最短停頓 | 兩句之間至少要安靜多久才算斷句（秒）。預設 0.3 秒 |

## 第三步：邊聽邊修

按 ▶ 播放，游標停在下一句，聽到那句開頭就按 **Enter（標記本行）**，時間碼會寫進那一行並自動跳到下一句。

常用按鍵與按鈕：

- **−3s / +3s**：倒帶或快轉，找段落用。
- **A− / A+**：調整播放速度（慢速跟唱時很好用）。
- **設人聲起點**：前奏很長、歌詞從很後面才開始時，先把第一句釘在正確位置。
- **編輯歌詞**：回到歌詞欄位修改文字，已標好的時間會盡量保留。

## 第四步：更準的兩種輔助

兩個都需要**第一次使用時下載模型**（之後會存在瀏覽器快取裡）：

- **用模型判斷人聲**：用語音活動偵測分辨「哪裡真的有人在唱」，遇到長間奏或樂器獨奏時特別有用。
- **用語音辨識對齊歌詞**：直接把聽到的語音與你貼的歌詞比對，自動找出每一句的位置。這是最省力也最準的一種，但第一次下載模型要一點時間。

## 第五步：輸出

右側「輸出」區塊填好標籤資訊，再選格式：

- `[ti]` 標題、`[ar]` 演出者、`[al]` 專輯、`[by]` 製作者 —— 會寫進 .lrc 檔頭。
- **加上 BOM**：給某些老播放器（尤其是 Windows 上的車機、舊版 foobar2000）用的，正常情況不用勾。
- 輸出 `.lrc` 或 `.srt`，字幕軟體（剪映、Premiere、YouTube 上傳）吃 .srt。

## 常見問題

**時間碼整體偏移？**
通常是音檔前後有靜音。用「設人聲起點」重新釘第一句，或整份用 A−/A+ 對照後微調。

**一句話被切成兩行？**
調低靈敏度，或把「最短停頓」加大。

**能不能直接抓現成的歌詞？**
工具不做這件事。歌詞請自備，並注意你用於公開場合的授權。
