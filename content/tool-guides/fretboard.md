# 世界樂器指版與和弦圖　使用說明

## 這個工具在做什麼

把常見彈撥樂器的調弦法、和弦按法與指版音位整理在同一頁。選一件樂器、選一個調，就能看到該調的順階和弦、每個和弦的按法，以及整條指版上的音。

支援 19 種樂器，包含吉他、烏克麗麗、班卓琴、曼陀林、琵琶、中阮、月琴、三線等。所有計算都在瀏覽器裡完成，不需要連線。

## 第一步：選樂器與調弦法

1. 在「樂器」選單挑一件樂器。
2. 如果這件樂器有多種常見調弦（例如吉他的標準調弦、Drop D、開放 G），「調弦法」會列出可選項；換調弦，下面所有的和弦圖與音位圖都會跟著重算。

還沒決定要學哪一件？先讀[樂器百科的分類頁](../instruments/)挑一件，再回來這裡試按法。

## 第二步：選根音與調式

- **根音（Root）**：這個調的主音。
- **調式 / 音階**：大調、自然小調、五聲、藍調等。選好之後，指版上會標出這個音階的音，順階和弦也會換成該調式的组成。

兩者合起來就是「這個調要用哪些音、哪些和弦」。

## 看圖的方式

| 顯示項目 | 意思 |
|---|---|
| 順階和弦 | 這個調裡自然會出現的和弦（I、ii、iii、IV、V、vi、vii°），流行歌大多在這裡面 |
| 和弦圖 | 直向是琴頸朝上的常見畫法；可切成橫向，和手機上的和弦 App 一致 |
| 指版音位圖 | 整條指版上每個音的分布，用來找相同音、找把位 |
| 組成音 | 把和弦拆成根音、三度、五度、七度，看得出它為什麼叫這個名字 |
| 和弦結構 | 標出和弦的音程結構，方便理解轉位與變化和弦 |

滑過或點和弦圖可以聽該和弦的實際音高（需要瀏覽器支援 Web Audio）。

## 幾個常用開關

- **橫向顯示和弦圖**：琴頸擺橫的畫法，適合手機或習慣橫向譜的人。
- **左撇子模式**：整張圖左右鏡射。
- **大小**：調整圖的比例，投影上課或列印時很好用。
- **顯示組成音／和弦結構／播放音高按鈕**：嫌圖太雜就關掉。

## 常見問題

**為什麼某個和弦沒有圖？**
那個和弦在這個調弦下指型跨距太大或不在常用把位，工具只畫實際按得出來的。

**為什麼跟我記的按法不一樣？**
同一個和弦常有多種按法（不同把位、不同轉位）。工具畫的是最常用的其中一種；把位不同不代表錯。

**可以列印嗎？**
可以，把「大小」調大、切換成直向或橫向後直接列印，圖會跟著放大。
