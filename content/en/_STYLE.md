# English edition — style and terminology

Every English lesson on this site is a translation of a Chinese original that
lives in `content/<course>/`. This file is the shared contract: read it before
translating anything. It is not built into the site.

## Voice

The Chinese originals have a specific voice. Keep it:

- **Direct, second person.** "You pluck the string and the air moves." Not
  "one may observe that".
- **Concrete before abstract.** Every claim gets a physical example a reader can
  try in ten seconds.
- **Plain words over jargon**, and when jargon is unavoidable, define it in the
  same sentence.
- **No hype.** No "amazing", "unlock", "master", "game-changing". The Chinese
  has none, so the English must not add it.
- **Short sentences.** If a translated sentence runs past ~35 words, split it.

Translation, not adaptation: keep every argument, example, figure reference and
exercise in the same order as the original. Cut nothing, invent nothing.

## Structure

- Same heading levels and same order as the source (`#` title, `##`, `##`, `###`).
- Lesson titles: `# Lesson 3: ...` for songwriting; `# Chapter 7: ...` for theory;
  vocal/digitalmusic use `# 第 N 章：…` → `# Chapter N: ...`.
- Tables keep their columns; translate cells only.
- Block quotes keep `>`.
- Exercises keep the "Try it now" / "After the exercise" pair.
- Keep paragraph breaks exactly where the source has them — the layout depends
  on them (a list with no blank line before it renders as literal `-`).

## Images

Figures are generated by the Python figure builders. English figures live at
`/assets/<course>/en/<name>.svg`. When a translated lesson references a figure,
use the English path:

```
![Alt text that describes the figure](/assets/musictheory/en/piano-range.svg)
```

If an English figure does not exist yet, still write the English path — the
figure builders are run with `--lang en` and fill them in. Never point an
English lesson at a Chinese figure.

## Things that do not get translated

- Code, file paths, chord symbols (`C`, `Am7`, `G/B`), note names, Hz values.
- Song titles: give the original title, then an English gloss in parentheses on
  first mention if it matters.
- Chinese instrument names that are already English loanwords (guzheng, pipa,
  erhu, dizi) stay romanised, with a one-line description the first time.

## Numbers and units

Chinese counts characters; English counts words. Keep the numbers from the
source but convert the unit: 三百字 → "three hundred characters" only when the
point is the Chinese text; otherwise rephrase ("a paragraph"). Bar counts and
Hz values never change.
