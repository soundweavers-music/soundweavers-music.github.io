# Lesson 2: Projects, Saving, and Auto-Save

## Why you have to understand "where it saves to"

The easiest trap in browser software is not the controls, it is **thinking you saved when you didn't**. This software has three layers of protection, but each one does a different job:

| Name | Where it lives | What it's for | Automatic? |
|---|---|---|---|
| Auto-save | This browser's IndexedDB | Coming back after a power cut, a crash, or a closed tab | Yes (every few seconds) |
| `.zyproj` file | The folder you choose | Backup, moving to another computer, sending to someone | Manual |
| Exported audio | The folder you choose | The finished piece | Manual |

**Auto-save only recognises "the same browser"**. Change browser, change computer, clear the site data, and the auto-save is gone. A project you really want to keep has to be saved as a `.zyproj`.

## How to do it

![Figure: the project name in the top left, with Save, Import and Export in the File menu beside it.](/assets/daw-course/en/daw-02-project.webp)

1. **New project**: File → New Project. A new project starts with **2 audio tracks + 1 MIDI track**; press "+ Audio" and "+ MIDI" when you need more.
2. **Save**: File → Save (Ctrl+S). The first time it asks you to choose a folder; after that Ctrl+S overwrites directly. To keep versions, use Save As (Ctrl+Shift+S).
3. **Open**: File → Open project (Ctrl+O).
4. **Take it with you**: just copy the `.zyproj` to a cloud drive or a USB stick — it holds only the project settings and the audio files, none of your other data.

## How it works: what's inside a `.zyproj`

A `.zyproj` is a ZIP container (stored uncompressed, so the file ends up as big as the project, but writes are faster), holding:

- `project.json`: tracks, effects, automation, master settings
- `audio/`: the audio files you imported or recorded (which is why the file gets big)

That is also why **the same project should sound the same on another computer**: the waveforms and the effect settings travel with it. The only thing that doesn't travel is the SoundFont library you use (those are files you downloaded yourself).

## Common mistakes

- **You pressed Ctrl+S but nothing was actually saved**: if the browser can't write straight into a folder, it turns into a download; watch the download bar.
- **Opening a new project while recording**: it asks "not saved yet, are you sure". Don't hit OK out of habit.
- **Using a private window**: the auto-save disappears when you close the window, so record in a normal window.

## Try it now

Save a `.zyproj` once, close the tab, open the software again, and use Open to load the file back. Check that the clips, the effects and the master settings are all still there.
