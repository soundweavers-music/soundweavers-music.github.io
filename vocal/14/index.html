🌱 初階篇

畫出情緒線：讓唱歌像說故事一樣自然 (基礎的情感量化與段落分配)

初階篇：啟蒙與覺察

先講結論

唱得有感情，不是唱到聲嘶力竭，是知道什麼地方該收、什麼地方該放。把一整首歌從頭到尾都唱得激烈，聽起來只會累。

這一章要你在歌詞上標數字，替每個段落訂一個情緒的強度，然後照著唱。有了地圖，你才不會憑當下的心情亂衝。

常見誤解

很多人以為「有感情就是要放飛自我」，眉頭一皺、聲音一啞，就是投入。其實那是失控。情緒一失控，氣息先亂，喉嚨接著夾緊，聲音很快就會壞掉。

另一個誤解是「情緒不能設計，設計就不真」。演戲也是照劇本演的，但你還是會哭。有設計不等於假，有設計才穩定，穩定才傳染得出去。

還有一個誤解是「小聲就等於沒感情」。最感人的地方，往往是最小聲的那一句。小聲需要更多支撐，不是更少。

原理：為什麼會這樣

情緒的強弱可以量化。把一首歌的情緒分成一到十分，這個分數不只是音量，還包含語氣、氣流量與支撐、共鳴的位置。一分是自言自語，五分是對面聊天，八分是對著廣場說話，十分是快要控制不住的那一瞬間。

一首歌的完整結構大概是主歌、副歌、間奏、再一次主歌、副歌、橋段、最後副歌。分數不是每段都往上加，它要有起有落。第一次副歌如果就到十分，最後一次副歌就沒地方去了。

換氣也是情緒的一部分。很多人把換氣當成「補充氧氣」，所以偷偷吸、快快吸，聽起來很趕。換氣如果放在對的地方，它可以變成一種停頓、一種嘆息、一種蓄力。這是免費的表情。

現在就做

練習一：標一張情緒地圖

  1. 把歌詞印下來或抄下來，保留段落順序。
  2. 第一次主歌標三分，第一次副歌標七分。
  3. 第二次主歌標四分（比第一次多一點情緒），橋段六分推到八分。
  4. 最後一次副歌標九分或十分。把分數寫在歌詞旁邊。

做錯會怎樣：如果每一段都標八分以上，這張圖就沒有用了。回頭把開頭壓到三分，讓後面有地方可以升。

練習二：用說的演一次

  1. 不唱歌，只用說的把歌詞唸完。
  2. 三分的地方，想像聽眾坐在你對面一步的距離。
  3. 八分的地方，想像聽眾在對街。
  4. 每次換段落，身體要真的切換，不是只有音量變。

做錯會怎樣：如果唸到八分時聲音破掉，代表你一次跳太多。從五分開始，一段一段加上去。

練習三：設計三種換氣

  1. 在句子中間標「v」，代表快速、無聲地偷一口氣。
  2. 在主歌標「h」，代表嘆氣式的吸氣，讓它聽起來像在忍。
  3. 在進最後副歌前標「V!」，代表明顯、深沉地吸一口。
  4. 照著符號唸一次，感受換氣如何改變句子的意思。

做錯會怎樣：如果每個地方都標「V!」，整首歌會像在喘。大口的換氣留給真正需要的地方，一次就好。

練習四：用畫面代替情緒

  1. 選一個你唱起來最有感覺的段落。
  2. 不要在唱的時候回想自己的傷心事，改想一個畫面：例如雨滴在玻璃上慢慢滑。
  3. 用那個畫面的節奏去唱，而不是用回憶的情緒去唱。
  4. 錄一次，聽聲音有沒有變穩。

做錯會怎樣：如果一想到真實的傷心事就唱不下去、開始哽咽，那就是情緒壓過了控制。畫面法的目的，是讓你被畫面帶著走，而不是被回憶淹沒。

練習五：照表唱一遍

  1. 看著你標好分數和換氣點的歌詞，配上伴奏唱一次。
  2. 每一段開始前，先看一眼那個數字，再開口。
  3. 唱完後對照：哪一段你唱得比標記大，哪一段比標記小。
  4. 只修最偏的那一段，其餘先不要動。

做錯會怎樣：如果每一段都偏大，那是緊張，不是設計。把整張圖往下壓一格，先讓身體習慣收。如果唱到一半忘記看，就先放下伴奏，只用手指著歌詞練。

練完之後

做對的徵兆：整首歌聽起來有高低起伏，不是平的；最強的地方之所以強，是因為前面有收；唱完之後情緒是釋放的，不是虛脫的。

常見卡點是「越唱越嗨」。唱到副歌情緒一上來，分數就失控，後面全部變大聲。練習時可以開節拍器或看著自己標的分數唱，提醒自己回到設定。

另一個卡點是「只有大聲和小聲」。同樣是三分，也可以有「冷」的三分和「暖」的三分，差別在音色和咬字。分數只是骨架，語氣才是血肉。

下一個要處理的是保養。聲音是消耗品，會用也要會養。
