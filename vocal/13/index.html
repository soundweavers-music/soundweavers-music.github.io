🌱 初階篇

定 KEY 的藝術：找到最舒適的表達音區 (無音樂基礎者的簡易音域測試法)

初階篇：啟蒙與覺察

先講結論

唱起來卡，很多時候不是技巧的問題，是這首歌的音高不適合你。每個人的聲帶長度、厚度、共鳴腔大小都不一樣，適合的音域也不同。

這一章教你用手機的升降 KEY 功能，測出這首歌對你來說「最高音在哪、最低音在哪」，然後調到兩端都唱得出來的位置。不用懂樂理，也不用有絕對音感。

常見誤解

很多人以為「降 KEY 就是認輸，能用原 KEY 唱完才叫會唱」。這個想法會讓你受傷。原唱定那個 KEY，是因為那個音高適合他的聲帶。你硬套別人的 KEY，等於穿別人的鞋跑步。

另一個誤解是「唱不上去，多練幾次就上去了」。如果是音高超過你目前的範圍，多練只會讓喉嚨愈來愈緊。音域可以慢慢拓展，但不是靠硬撐同一首歌。

還有一個誤解是「升 KEY 一定比較難」。對低音比較弱的人來說，升 KEY 反而讓主歌變得容易唱，只是副歌要重新確認。

原理：為什麼會這樣

一首歌的音域，是它最高音和最低音之間的距離。每個人也有一個目前唱得舒服的範圍。把歌放進你的範圍，就像把畫放進畫框：同一個畫框，你決定擺在牆上的哪個高度。

KEY 高的時候，你要花力氣去搆最高音，氣不夠、咬字就顧不到，副歌會變成在「求生」。KEY 低的時候，主歌掉到你的說話音高以下，聲音會虛、會被伴奏的低音蓋掉。兩種都不好唱。

所以定 KEY 要測兩端，不是只測最高音。先找最高音的天花板，再回頭檢查最低音有沒有掉出去。兩端都過，才是你的 KEY。

還有一個實務問題：伴奏帶是數位升降的。升降幅度小的時候，聽不太出來；幅度一大，鋼琴、吉他、鼓的音色會變得奇怪，聲音會糊。這是工具的限制，不是你的問題。能小調就小調，需要大調就換一個現成的降調伴奏。

現在就做

練習一：直接攻最高音

  1. 挑一首你一直覺得「很難唱」的歌，找出全曲最高的那一句，通常在最後一次副歌。
  2. 播原 KEY 伴奏，只唱那一句。
  3. 檢查三件事：脖子有沒有變粗、下巴有沒有往前伸、聲音有沒有變成喊的。
  4. 如果三項有任一項成立，就是紅燈。

做錯會怎樣：如果紅燈了還反覆硬唱，聲帶會開始疲勞，後面測什麼都不準。一次不對就降 KEY，不要戀戰。

練習二：一次降半音，慢慢找

  1. 把伴奏降一個半音，再唱同一句。
  2. 還緊就再降半音，一次只降一格。
  3. 停在一個「唱得上去、喉嚨不痛、還能拉長」的位置。
  4. 把這個數字記下來。

做錯會怎樣：如果一次降太多，你會不知道最緊的那一格在哪。一次一格，寧可多測幾次。如果降到很低還緊，問題可能不是 KEY，是這一句的發聲方式，回頭看前一章。

練習三：回頭檢查最低音

  1. 用剛才找到的 KEY，回到第一段主歌的第一句，那通常是全曲最低的地方。
  2. 用說話的音量唱，不要刻意壓低。
  3. 檢查：字清不清楚、胸口有沒有震動、聲音有沒有消失。
  4. 如果主歌掉出去了，往上調一格再測。

做錯會怎樣：如果為了唱低音把下巴壓進脖子，聲音會悶住。那是壓出來的不是唱出來的，主歌的低音不該用這種方式產生。

練習四：記下你的密碼

  1. 在歌單上寫下這首歌對你的 KEY，例如「降二」。
  2. 同樣的方法測三首歌，看看數字有沒有接近。
  3. 如果三首都在附近，那就是你目前最舒服的區間。
  4. 下次點歌，先照這個數字調，再微調。

做錯會怎樣：如果三首差很多，是正常的，因為每首歌本身的音域不同。重點不是同一個數字，是每次都測兩端。

練完之後

做對的徵兆：副歌最高音唱得上去、還能做漸弱；主歌最低音清楚、有厚度；整首唱完喉嚨不痠。

常見卡點是「高音剛好，低音卻唱不出來」。這代表這首歌的音域跨度比你目前的範圍大。這不是你的錯，也不是這首歌的問題，只是它現在不適合你。先放著，練別的，範圍會慢慢變寬。

另一個卡點是「在 KTV 不敢降」。唱歌是給人聽的，不是比賽。降 KEY 之後唱得穩、唱得有感，比硬撐原 KEY 破音好聽太多。

下一個要處理的是情緒的分配：同一首歌，什麼地方該收，什麼地方該全放。
