長弦樂器是弦鳴實驗樂器，以極長弦使基頻低於人耳可聽的約二十赫茲，產生拍頻與較高自然泛音；攻擊音沿弦以縱波傳播，形成類似科幻雷射槍或火車電力纜線的聲音。美國作曲家 Ellen Fullman的版本約有二十七公尺長弦，以C型夾張緊，末端置共鳴器，演奏者沿弦走動，以塗松香的手摩擦弦。此類樂器亦由 Alvin Lucier、Terry Fox、Jon Rose、Paul Panhuysen、George Smits、Yuri Landman 及葡萄牙波爾圖 Sonoscopia等用於錄音、演奏與聲音裝置。

聆聽示範

聆聽示範見於實驗音樂與聲音裝置場合。Ellen Fullman以約27公尺長弦、純律調音，演奏者沿弦走動並以塗松香的手摩擦；Alvin Lucier在《Music on a Long Thin Wire》使用最多25公尺單弦；Terry Fox以《Berlin Attic Wire, Beating》錄音；Jon Rose拉奏世界各地圍欄；Yuri Landman留有便攜電動長弦獨奏錄音；波爾圖Sonoscopia有永久電動放大長弦。

歷史背景

長弦樂器曾由梅森用於測試伽利略假設，使弦振動速度可見可數；0.33公尺弦發440赫茲，同質量張力而長8倍的2.64公尺弦發55赫茲。1977年，阿爾文·盧西爾以最多25公尺單弦琴創作；1981年泰瑞·福克斯錄製兩曲；1983年起強·羅斯拉奏世界各地圍欄。艾倫·富爾曼發明約27公尺長弦樂器，以純律調音，演奏者沿弦走動並以塗松香的手摩擦。潘豪森、史密茨、蘭德曼與波爾圖聲學研究中心亦發展大型裝置、保麗龍放大、便攜電動與永久電動版本。

音色描述

長弦樂器的基頻常低於人耳可聽範圍，發聲不依賴可聽基頻，而以拍頻與較高自然泛音為主；弦長造成短至約五至十公尺的混響，或超過十公尺的較長回聲。起音以縱波沿弦傳導，產生類似雷射槍與火車上方電力纜線的聲音。艾倫·富爾曼的版本以中央C所在八度為中心，上下各延伸一個八度，低音八度弦可達全長。音量與共鳴由C型夾張力、塗松香的手摩擦、末端共鳴器，以及電氣或保麗龍擴音方式決定。

樂器材質

來源僅載明部分材質：長弦樂器以長弦或細長線發聲；Fullman 版本每條弦以 C 型夾張緊，演奏者以塗松香的手摩擦，弦端設共鳴器，但未說明弦、夾具與共鳴器材質。Lucier 使用可達二十五公尺的細長線；Smits 以保麗龍作聲學放大；另有電動長弦樂器，來源未載明琴身、線材或電子部件材質。

長弦樂器固定於空間，不抱持。演奏時先以夾具逐弦調緊，並將共鳴器置於演奏者面對的一端。演奏者沿著長弦行走，以塗松香的手摩擦弦，產生縱向振動。音域以中央C所在八度為中心，上下各延伸一個八度；低音八度的弦可延伸至全長。電聲版本的操作細節來源未載明。
