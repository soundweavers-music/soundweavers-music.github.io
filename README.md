# 世界聲音 · World Sound

世界樂器・人聲歌唱・音樂文化 — 循著聲音，走進不同文化的現場。

🌐 **網站：** <https://soundweavers-music.github.io/>

這個 repo 是網站內容與建置腳本的私人工作區，**不是對外的範本或教學**；要認識這個網站，直接打開上面的網址就好。

## 這個網站在做什麼

一個不用安裝、檔案不上傳的音樂學習網站：從世界樂器的分類百科，到歌唱、樂理、錄音後製與 DAW 編曲課程，再加上幾支直接在瀏覽器裡跑的工具。全站有**繁體中文、簡體中文、英文**三種版本，可以切換深色／淺色主題。

## 內容

**🌍 世界樂器（826 件）**
依 Hornbostel–Sachs 分類整理，每一件都有國家／地區、發聲原理、圖片與示範影片；可以用分類、國家、地圖或全文搜尋（中名、原文名、別名）找到樂器。資料以英文維基、中文維基、Wikidata 交叉查證，來源不足的段落會直接標示，不以臆測內容充數。

**🎶 合奏與編制百科（B1–B7，40 種編制）**
從地域傳統合奏、民間樂隊、鼓樂與節慶編制，到古典大型編制、現代民族樂團、爵士與流行編制、現代混合與跨界，說明每一種編制裡有哪些樂器、怎麼分工。

**🎧 聲音旅圖**
用六段聲音旅程串起網站——在世界出發以前，耳朵先在隔壁家醒來。

**📚 課程**
- 人聲與歌唱：初階 15 堂、進階 35 堂、研究專欄 5 篇
- 樂理基礎：五階段二十章
- 錄音後製：基礎 15 堂、進階 15 堂
- 流行歌曲詞曲創作：6 堂
- 曼陀林專區：22 章
- 流行吉他彈唱指南：25 章
- 烏克麗麗流行彈唱與演奏：25 章
- 線上編曲製作（DAW）操作課：24 堂
