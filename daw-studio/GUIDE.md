# 織音線上編曲製作　使用說明

織音線上編曲製作是一套在瀏覽器裡執行的編曲軟體（DAW）。不用安裝、不用註冊，打開網頁就能錄音、編 MIDI、混音、做母帶，最後輸出成音檔。

[**▶ 開啟織音線上編曲製作**](../)

## 你的檔案不會離開電腦

這個頁面的安全政策（Content-Security-Policy）設定為 `connect-src 'self'`：瀏覽器會擋下這個頁面對**其他任何伺服器**發出的連線，只允許讀取本站自己的程式檔（AI 人聲分離的執行引擎）。本站是純靜態網站（GitHub Pages），沒有任何可以接收檔案的地方。所以不是「我們承諾不上傳」，而是**技術上就沒辦法上傳**。

- 錄音、匯入的音檔、MIDI、效果器設定，全部只在你的電腦上處理。
- 專案存成 `.zyproj` 檔，放在你自己選的資料夾。
- 瀏覽器會另外自動暫存一份（IndexedDB），關掉分頁再打開時可以還原。暫存只在這台電腦的這個瀏覽器裡，清除瀏覽資料就會消失，重要的專案請按「儲存」另存檔案。

## 建議環境

| 項目 | 建議 |

## 畫面介紹

- **上方控制列**：新增／開啟／儲存專案、匯入音檔與 MIDI、播放控制、小節與時間顯示、速度（BPM）、拍號、節拍器、對齊格線，右側是各面板的開關與「輸出」。
- **左側檢閱器**：目前選取軌道的名稱、顏色、音色、插入效果器、Send，以及這一軌和 Master 的推桿。
- **中間編排視窗**：每一列是一條軌道。左邊是軌道標頭（M 靜音、S 獨奏、R 錄音待命、I 輸入監聽、音量），右邊是時間軸上的片段。
- **下方面板**：混音台、鋼琴捲簾、母帶，一次顯示一個。
- **設定 ▾**：音訊裝置（麥克風輸入、播放輸出、緩衝區）、MIDI 設定、錄音延遲校正、音色庫，以及**配色**都集中在這裡。配色共有 20 套（預設是「專業深色」，「世界聲音・木質深色／淺色」和世界聲音網站同一套色票，其餘是午夜藍、森林綠、夕陽橙、夜酒紅、深海青、薰衣草紫…等），選單右邊的三格色票就是該套配色的背景色、主色與文字色，選之前就看得到樣子；選擇會記在這個瀏覽器裡。

左上角的「**首頁**」按鈕會回到世界聲音；專案已經自動暫存，回來時可以還原。

## 快速開始

### 用音檔做混音

1. 把音檔（WAV、MP3、FLAC、OGG、M4A）**拖進音訊軌**，或在空白處雙擊選檔。一次拖多個檔案會自動往下排到不同軌。
2. 按**空白鍵**播放。點上方尺規可以移動播放頭。
3. 按「混音台」調整每一軌的音量與左右位置。
4. 按「輸出」，選格式，檔案會直接下載到你的電腦。

### 錄音

1. 按某一條音訊軌的 **R**（錄音待命）。第一次會詢問麥克風權限。
2. 想一邊錄一邊聽自己的聲音，再按 **I**（輸入監聽，請戴耳機以免回授嘯叫）。
3. 需要預備拍就按上方的「1234」，錄音前會先響一小節節拍器。
4. 按紅色**錄音鍵**（或鍵盤 R）開始，再按一次或按停止結束。
5. 新錄的內容會蓋掉同一段時間裡的舊片段（punch-in）。

錄音自動扣掉瀏覽器回報的延遲。如果錄好的聲音總是比節拍晚一點，到下方狀態列按「校正」微調。

### 用 MIDI 編曲

1. 新專案預設 **2 條音訊軌 + 1 條 MIDI 軌**（鋼琴），軌號旁邊有 ♪ 記號；不夠用時按「＋ 音訊」「＋ MIDI」再加，最多 32 軌。
2. 在 MIDI 軌上**雙擊**，會建立一個 4 小節的空白片段並打開鋼琴捲簾。
3. 在鋼琴捲簾上**點一下**新增音符，拖曳可移動，拖右緣可改長度。
4. 在檢閱器的「音色」選單換樂器。

## 編輯片段

| 動作 | 方法 |
|---|---|
| 移動 | 拖曳片段 |
| 複製 | 按住 Alt 拖曳，或 Ctrl+D 接在後面 |
| 修剪頭尾 | 拖曳片段左右邊緣 |
| 淡入／淡出 | 拖曳片段上緣左右兩端的小圓點 |
| 切開 | 播放頭移到要切的位置，按 Ctrl+T |
| 框選多個 | 在空白處拖曳；Shift 加選 |
| 刪除 | Delete |
| 微調位置 | 方向鍵左右，一次移動一格格線 |
| 復原／重做 | Ctrl+Z ／ Ctrl+Shift+Z |

格線大小會跟著縮放自動切換（小節、拍、八分、十六分）。按 **G** 或上方「對齊」可以關閉吸附，自由擺放。

**循環播放**：在尺規最上緣拖出一段範圍，按 **C** 開關循環。

## MIDI

### 鋼琴捲簾

- **點空白**：新增音符（長度沿用你上一次調的長度）
- **拖曳音符**：移動；**拖右緣**：改長度；**Alt 拖曳**：複製
- **Shift 拖曳空白處**：框選
- **右鍵**音符：刪除
- 下方力度條：拖曳調整音符力度
- 工具列：格線（1/4 到 1/32、三連音）、**量化**（Q）、移調（↑↓，Shift 為八度）

鼓組軌的左側琴鍵會顯示 GM 鼓位名稱（大鼓、小鼓、閉合鈸……），直接點對應那一排即可。

### 彈奏與錄 MIDI

- **MIDI 鍵盤**：插上就能用（Chrome / Edge）。上方的小圓燈有訊號時會閃。
- **電腦鍵盤彈奏**：按 **Caps Lock** 開關。A S D F G H J K L 是白鍵，W E T Y U O P 是黑鍵，Z / X 換八度，C / V 調力度。
- **錄 MIDI**：按 MIDI 軌的 R，再按錄音鍵，邊彈邊錄成新的 MIDI 片段。
- **延音踏板**：接在 MIDI 鍵盤上的踏板（CC64）會被錄下來。音符長度記錄的是「手實際按住的長度」，踏板另外記在鋼琴捲簾下方的「踏板」列，播放時再把延音套上去——所以鋼琴捲簾不會被踏板拉成一大片重疊的長條。踏板列可以直接編輯：點空白新增一段、拖兩端改長度、右鍵刪除。匯出／匯入 .mid 時踏板也會一起保留。
- **輸入移調**：上方的「− 0 ＋」可以讓鍵盤彈的音整體升降（±24 半音），錄進去的就是移調後的音。快捷鍵 `[` `]` 一次半音、`Shift+[` `Shift+]` 一次八度，雙擊數字歸零。

### 匯入／匯出 .mid

上方「匯入 MIDI」或直接把 .mid 拖進編排視窗，每一軌會變成一條 MIDI 軌，並依原本的樂器編號挑選接近的音色。專案還是空的時候，會採用 MIDI 檔的速度與拍號。在「輸出」選 MIDI 格式，或在片段上按右鍵「匯出成 .mid」。

### 改速度

MIDI 片段以拍數記錄，改 BPM 時會跟著小節走。音訊片段的起點也會移到同一個小節位置，但音訊本身不會被加速或減速。

## 音色

### 內建音色

不需要下載：平台鋼琴、電鋼琴、管風琴、弦樂合奏、弦樂撥奏、溫暖 Pad、方波 Lead、合成撥弦、合成貝斯、指彈電貝斯、鐘琴、木琴，以及 GM 鼓組。

### SoundFont 音色庫

想要更真實的樂器聲，可以載入 SoundFont（.sf2）。按上方「**音色庫**」：

1. **下載**：對話框裡列了三套免費音色庫，按「下載」就會從官方來源下載到你的電腦。最推薦先用 **GeneralUser GS**（31 MB）。
2. **自動載入**（Chrome / Edge）：按「設定下載資料夾」選一次你的「下載」資料夾。之後下載完成、切回這個分頁，就會自動找到並載入。網頁只讀取資料夾裡的 .sf2，不會上傳或修改任何檔案。重新打開網頁後，瀏覽器可能要你再按一次「允許讀取」。
3. **手動載入**：也可以直接把 .sf2 拖進對話框。

載入後的音色庫會記在這個瀏覽器裡，下次打開不用重選。到 MIDI 軌的檢閱器「SoundFont 音色」選單挑選樂器。

> 不支援 .sf3（壓縮格式），請下載同一套音色庫的 .sf2 版本。專案檔只記錄你用了哪一套音色庫，不會把音色庫打包進去；在別台電腦開啟時，要先載入同一套音色庫，否則會用內建音色代替。

## 效果器

每一軌可以掛 6 個**插入效果器**：在檢閱器或混音台點「＋」新增，點一下效果器名稱打開參數面板。每個效果器都有**預設值選單**，挑一個最接近的再微調最快。

| 效果器 | 用途 |
|---|---|
| **人聲修音** | 依調性把唱歪的音拉準；可以很自然，也可以做出機械感的電子人聲。詳見下方「人聲修音」。 |
| **Harmony 人聲和聲** | 從一條主唱即時產生 1～4 部和聲，可以依調性或依伴奏的和弦，也能依小節切換不同的和聲。詳見下方「人聲和聲」。 |
| **EQ 等化器** | 8 段參數 EQ。曲線上的圓點可以直接拖曳（左右改頻率、上下改增益，滾輪改 Q 值），播放時背景會即時顯示頻譜。預設值有人聲、木吉他、鼓組、貝斯、溫暖、明亮、電話音效等。 |
| **Compressor 壓縮器** | 控制動態，讓忽大忽小的聲音變平均。預設值有人聲、鼓組、貝斯、溫和平衡、強力壓縮等，面板會即時顯示壓縮量。 |
| **De-esser 去齒音器** | 只壓「ㄙ、ㄘ、ㄕ」這類尖銳的齒音（約 4–10 kHz），其他頻率不受影響。可以開「只聽被壓的部分」找出齒音在哪。 |
| **Saturation 飽和度** | 磁帶、真空管、電晶體、硬削波四種特性，從溫暖的微失真到明顯破音。 |
| **Reverb 殘響** | 六種空間（房間、大廳、板式、教堂、彈簧、閘門）＋早期反射、調變與立體寬度。面板左邊畫空間剖面、右邊畫低頻／高頻兩條衰減曲線，依樂器分類的預設值有 9 組。詳見下方「殘響」。 |
| **Stereo Width 立體聲寬度** | 把單聲道來源（木吉他、單支麥克風的人聲、貝斯）變成有寬度的立體聲，也可以把既有的立體聲再拉寬。面板上有立體聲向量示波器與相關度表。詳見下方「立體聲寬度」。 |
| **Delay 延遲** | 回聲，時間以拍為單位，會跟著 BPM；可開左右彈跳。 |
| **Chorus 合唱** | 讓聲音變寬、變厚。 |
| **Distortion 失真** | 比較兇的破音。 |
| **Noise Gate 噪音閘** | 安靜時把底噪關掉。只在即時播放時作用，輸出檔案時會略過。 |
| **Pitch 即時移調** | 做和聲、八度疊加、雙重人聲等效果（附預設值）。即時運算，音準會有輕微顫動；要把整段轉調請用下方的「片段升降音」。 |

效果器槽的 ● 可以暫時關閉（bypass）；右鍵可以調整順序或移除。

效果器面板可以**同時開好幾個**（例如一邊看 EQ、一邊調壓縮），新開的面板會錯開排列；點一下面板就會移到最上層，拖曳標題列可以移動。按 **Esc** 關掉最上面那一個。拖曳面板**右下角**可以把視窗拉大（圖表會跟著變大），每種效果器會記住自己的大小；雙擊右下角還原。

### Send 匯流排

多條軌道共用同一個殘響，聽起來會在同一個空間裡，也比較省電腦資源。檢閱器的「Send」可以把每一軌送到：

- **Bus A 殘響**
- **Bus B 延遲**

匯流排本身的效果器與音量在混音台最右邊調整。

## 每一軌的移調

MIDI 軌的檢閱器有「這一軌移調」：±1 半音或 ±8 度。它只影響**播放與即時彈奏**，音符本身不會被改寫（要改寫請用鋼琴捲簾，或片段右鍵的「升降音」）。雙擊中間的數字歸零。

上排還有一個全域的 MIDI 輸入移調（`[` `]`），那是給「彈進去」的音用的，兩者可以疊加。

## 裝置設定

上排「設定 ▾ → 音訊裝置」（MIDI 鍵盤在「設定 ▾ → MIDI 設定」）可以選：

- **錄音輸入**：麥克風或錄音介面的輸入（授權後才看得到名稱）
- **播放輸出**：切換耳機／喇叭（瀏覽器支援 `setSinkId` 時可立即切換）
- **緩衝區（延遲）**：低延遲（錄音、即時演奏）、平衡、穩定。這一項要重新整理頁面才會生效；專案會自動暫存，不用擔心。
- **MIDI 輸入**：可以整組開關，也可以逐台勾選要用哪一台鍵盤

## 混音台

按「混音台」（X）。每一軌有效果器槽、Send A／B 小旋鈕、聲像、推桿、立體聲電平表、峰值與 M／S／R。峰值超過 0 dB 會變紅，點一下可以重設。

推桿與旋鈕：**雙擊**回到預設值，**Shift 拖曳**微調。

## 母帶與專輯（批次）

上排中間的「**母帶**」狀態列隨時顯示整合響度（LUFS）與 Limiter 的壓縮量（GR），顏色變黃代表超過目標響度；點一下就會打開母帶視窗。右邊的「專輯」是批次母帶：一次處理整張專輯（統一響度、淡入淡出），兩者都在上排就能直接開。

## 自動化

按「自動化」（A），每條軌道會顯示一條曲線：

- 在軌道標頭的選單選要自動化的參數：音量、聲像、Send A、Send B
- **點曲線**新增控制點，**拖曳**移動，**雙擊**或右鍵刪除
- 拖曳時按住 Shift 可以不吸附格線
- 標頭的黃色 **R** 是「讀取自動化」開關；關掉時用推桿的固定值

## 和弦軌

按上方的「**和弦**」按鈕，尺規下方會多出一條和弦軌，顯示每個段落在彈什麼和弦。

1. **抓和弦**：選一條軌（MIDI 軌最準，鋼琴、吉他、貝斯都可以），到檢閱器按「**偵測這條軌的和弦**」。程式會每拍分析一次色度，用 Viterbi 把零碎的判斷接成一段一段的和弦，同時推測這首歌的調性。
2. **顯示方式**：檢閱器可以切換
   - **音名**：C、Am、F、G
   - **級數**：I、vi、IV、V（換調也看得懂功能）
   - **首調（簡譜）**：1、6m、4、5（只會 C 大調和弦的人看這個最直覺）
3. **編輯**：點尺規下方的和弦方塊 → 選單可以改性質（大三、小三、屬七、大七、小七、掛四、減三）、調內七個級數、換根音、切成兩半、合併下一個、刪除。點空白處則是在那一小節新增和弦。
4. **套用**：
   - **套用到和聲**：Harmony 效果器切成「依和弦」，和聲只會落在和弦音上。
   - **套用到修音**：把人聲修音的主音與音階設成推測出來的調性。

和弦存成「拍」，改 BPM 時會跟著小節移動；專案存檔也會一起存。

## 智慧編曲

上方的「**✦ 智慧編曲**」按鈕（或自動伴奏視窗裡的「智慧整首編曲」）打開一個有三頁的視窗。全部在這台電腦上計算，不連網路。

### ① 旋律配和弦

1. 選**旋律軌**：錄好的主唱（音訊，最好是沒有伴奏的乾淨人聲）或寫好的 MIDI 旋律。MIDI 軌同時有好幾個音時，只看最高的那個。
2. 選**換和弦的密度**（每小節 1 個或 2 個），調性可以自動判斷，判斷錯了再手動選。
3. 按「**分析旋律**」。程式先找出調性，再用和弦機率模型（HMM／Viterbi）逐小節配和弦：
   - 旋律音落在和弦音上加分，正拍與長音比較重要；
   - 偏好華語流行常見的走法（I–V–vi–IV、IV–V–iii–vi、vi–IV–V–I、ii–V–I，偶爾用副屬和弦 III→vi）；
   - 開頭與結尾偏好主和弦，樂句結尾偏好 V。
4. 會給 2～3 個版本：**流行抒情**、**王道進行・七和弦**（加上 maj7、m7 色彩）、**簡單三和弦**（只用 I、ii、IV、V、vi，適合彈唱）。每個版本旁邊的「旋律貼合」是旋律音落在和弦音上的比例。旋律很明確時，跟第一個版本太像的版本不會列出來。
5. 按「**用這個版本**」寫進和弦軌（只取代旋律涵蓋的那幾小節）。之後可以在和弦軌上逐格改，或按「下一步」直接編曲。

### ② 一鍵編曲

依和弦軌與**段落表**，用自動伴奏的風格把整首編成鼓、貝斯、鋼琴、吉他、弦樂、琶音的 MIDI 片段，放進「伴奏-」各軌，可以再用鋼琴捲簾修改。

- **段落表**：打開時會自動排。和弦樣式重複最多、又出現在後面的那一段當副歌，前面當主歌，第二輪主歌用「主歌 B」，最後一輪副歌用「副歌 2」（最滿）。每一段都可以改段落種類、小節數、強度（弱 = 拿掉吉他與琶音；強 = 加弦樂、力度大一點），也可以上移、刪除、新增。
- **前奏／尾奏**：用風格自己的和弦進行。前奏放在和弦軌**前面**，所以和弦軌要從第 2 小節以後開始才放得下；尾奏接在後面，小節數 0 = 用風格的長度。
- **過門**：換段落的前一小節自動打過門；新段落第一拍加強音鈸；同一段落很長時，每 8 小節也可能打一個短過門。
- **變化**：越大，過門、鬼音小鼓、貝斯經過音、Voicing 與力度起伏越多。「**重新產生**」用同樣的設定換一版；每次都可以 Ctrl+Z 復原。
- **聲部勾選**：不要的聲部取消勾選就不會產生。
- 重新產生會取代上一次智慧編曲產生的片段，自己錄的伴奏片段不受影響。「移除智慧編曲」會拿掉全部智慧編曲的片段。
- 風格有建議速度，但**不會改專案的 BPM**；3/4 拍風格（華爾滋）要配 3/4 拍的專案。

### ③ 智慧創作

從零寫一首歌的骨架：和弦進行＋一條好唱的主旋律。

1. 選**調性**、**速度**、**曲式**（短版 16 小節／標準 40 小節／完整 52 小節，含橋段）、**音域**（低＝男聲、高＝女聲）、**旋律變化**與旋律音色。
2. 按「**✦ 寫一首新的**」。和弦從華語流行最常見的進行裡挑：主歌（卡農、1-5-6-4、1-6-4-5…）、導歌（4-5-3-6、2-3-4-5…）、副歌（4-5-3-6 王道、1-5-6-3-4-5 副屬…）；同一種段落重複時用同一組和弦，最後一輪副歌收在主和弦。
3. 主旋律走「安全」路線：正拍與長音落在和弦音、以五聲音階為主、多級進、大跳之後反向；節奏用一小節的動機重複（a b a c），副歌比主歌高、句尾落在穩定音，整首最後落在主音。第二輪主歌／副歌用同一條旋律（像真正的歌換歌詞）。
3. **和弦進行可以自己決定**：「和弦進行」區每種段落（主歌、導歌、副歌、橋段）各有一個選單——
   - **🎲 隨機**：每次抽一組常見進行（預設）；
   - **進行庫**：直接指定，例如副歌固定用「4-5-3-6 王道進行」，選單裡會顯示這個調的和弦名；
   - **✎ 自己寫**：輸入簡譜數字（`1 5 6m 4`、`2m7 5 1`、`b7`）、級數（`I V vi IV`、`ii7 V7`）或和弦名（`C G Am F`、`F#m7`），一個記號一小節，用 `+` 把兩個和弦放進同一小節（`4 5+3 6m`）。下方即時顯示會變成哪些和弦，看不懂的記號會標紅。寫得比段落長時段落會自動拉長（4 的倍數）。小調歌照簡譜習慣以關係大調為準：`6m` 是主和弦。
   指定的段落照你寫的走，不會被自動修改結尾；「重抽隨機和弦」只換標成隨機的段落。
4. 結果寫進和弦軌（從第 5 小節開始，前面留給前奏）與「**智慧主旋律**」軌；按「**只換旋律**」或「**重抽隨機和弦**」可以保留另一半重來。每次都可以 Ctrl+Z 復原。
5. 按「**下一步：配上伴奏**」會把曲式帶進 ② 一鍵編曲的段落表，直接產生整首伴奏。

目前只支援 4/4 拍。旋律是編曲草稿，歌詞與細節仍然要自己寫。

## 人聲修音

在人聲軌的效果器第一格加入 **人聲修音**，點開面板：

1. **設定調性**：選「主音」和「音階」，或按「🔍 偵測調性」讓程式分析這一軌（還沒錄音時會參考整首的 MIDI 軌）。也可以直接點面板右邊的小鍵盤，把某個音加入或排除（會變成「自訂」音階）。
2. **挑預設值**：一般唱歌建議用「**自然修音（推薦）**」，聽不太出處理痕跡；想要電子人聲效果就選「**機械音（T-Pain）**」。
3. **微調旋鈕**（拖曳上下、滾輪微調、雙擊回到預設）：

| 旋鈕 | 意思 |
|---|---|
| 修正速度 | 偏掉的音多快被拉回來。0 ms 是瞬間跳到（機械音）；40–70 ms 自然；100 ms 以上只修長音，保留滑音 |
| 修正強度 | 100% 拉到完全準；調低只修一部分，保留一點人味 |
| 保留顫音 | 只修正音高中心，保留原本的抖音。調低會把顫音拉平 |
| 濕度 | 混入多少原聲 |

「音域」選單可以配合歌手（男低音、女高音），偵測會更穩；樂器（例如小提琴、薩克斯風）選「樂器」。

面板上方左邊是**調音表**：指針在中間（綠色）代表唱得準，偏左是偏低、偏右是偏高。右邊的**音高曲線**同時畫出原本唱的（灰色）和修正後的（彩色），橫線是目前音階裡的音。

**邊唱邊聽修正後的聲音**：按下該軌的 **R** 和 **I**，戴耳機唱，耳機裡就會是修過的聲音。錄進去的仍是**原聲**，之後可以隨時改調性或設定，不必重錄。

**延遲**：修音需要約 32 毫秒分析音高。播放與輸出時會自動補償，跟伴奏完全對齊；只有錄音時的耳機監聽會晚約 32 毫秒，一般唱歌不太會察覺。

### 現場低延遲（16 ms）

面板中間有一顆「**現場低延遲**」開關，也有人用「現場演出（低延遲）」預設值。開啟後分析窗縮短一半，耳機監聽的延遲降到約 **16 毫秒**，邊唱邊聽幾乎沒有回音感；代價是最低音域只到 **100 Hz**（一般人的低音都在這之上，男低音最低的幾個音可能受影響），修正速度太快時也比較容易聽出機械感。錄音、排練、直播用現場模式；正式混音再切回標準模式。

### 音符編輯：一個音一個音指定

在人聲修音面板按「**🎼 開啟音符編輯器**」，會打開一個獨立的大視窗（可以拖曳右下角拉大、按 ▢ 或雙擊標題列最大化，大小會記住）。按「**分析這一軌**」，程式會把錄音切成一顆一顆的音符：藍色＝原本的音、粉紅＝改過音高的音；背景是人聲波形，左邊是鋼琴鍵（綠色標記＝音階內的音）。

| 操作 | 作用 |
|---|---|
| 拖曳音符 | 上下改音高（一次一個半音，按住 **Alt** 可以微調）、左右改時間 |
| 拖曳音符左右邊緣 | 改開始／結束時間 |
| 空白處拖曳 | 框選多個音；**Shift** 點選加選；**Ctrl+A** 全選 |
| **↑ ↓** | 選取的音升降一個半音（**Shift** = 10 cent） |
| **← →** | 前後移動（**Shift** 移得多一點） |
| 雙擊音符 | 從那裡切成兩個音 |
| **Delete** 或右鍵 | 刪除 |
| 滾輪／**Shift**+滾輪 | 上下／左右捲動 |
| **Ctrl**+滾輪、**Alt**+滾輪 | 縮放時間、縮放音高 |
| 點上方時間尺 | 播放頭跳到那裡；**空白鍵**播放／停止 |
| **F** 或「全部」 | 縮放到看得見所有音符 |

上方的按鈕：「**對齊音階**」把選取的音（沒選＝全部）拉到最近的音階音；「**回到原音**」還原成你唱的音高；「切開」在播放頭位置切開；「套用手動音符」取消勾選可以暫時回到依音階自動修正、比較差別。下方可以直接輸入選取音符的移調量，以及「修正強度」（0% 等於放掉這個音）。播放時開啟「跟隨」，畫面會跟著播放頭走。

編輯過的地方會**蓋掉音階規則**：例如某一句想唱藍調的降五度，把那個音拉到該音高、強度 100%，它就會被修到那個音，而不是被拉回音階音。音符的時間是跟著**專案時間軸**跑的，所以改了片段位置要重新分析一次。

小提醒：

- 修音只能修「單一旋律」，和聲、合唱、吉他和弦這類同時有多個音的聲音不適合。
- 先修音、再 EQ／壓縮／殘響；殘響放在修音前面會讓音高偵測不穩。
- 子音、氣音、無聲段落不會被處理，原樣通過。

## 殘響（Reverb）

殘響面板分三塊：上面是**空間類型**，中間是**圖**，下面是參數。

| 空間 | 聽起來 |
|---|---|
| 房間 Room | 反射近、密、乾淨，尾巴短 |
| 大廳 Hall | 尾巴慢慢堆起來，最通用 |
| 板式 Plate | 沒有離散的反射、一瞬間就是密的尾巴，人聲與小鼓常用 |
| 教堂 Cathedral | 建立得慢、反射稀疏、尾巴最長 |
| 彈簧 Spring | 金屬共振的「啾」聲，復古吉他音箱的味道 |
| 閘門 Gate | 尾巴到固定時間就被切掉，80 年代小鼓的經典聲音 |

中間的圖：左邊是**空間剖面**（綠色是音源、藍色是聽者，黃線是第一次反射，虛線是預延遲）；右邊是**衰減曲線**，綠色是低頻、藍色是高頻——兩條分得越開，「高頻衰減」就越明顯。閘門類型的紅色虛線就是尾巴被切掉的位置。

參數：尾巴長度、預延遲、高頻衰減、**早期反射**（牆面反射的量）、**調變**（尾巴微微飄動，板式與大廳的「活」感）、**立體寬度**、濕度。

**依樂器挑預設值**：人聲板式／大廳、木吉他小房間、鋼琴大廳、弦樂教堂、鼓房間／閘門、彈簧殘響、以及「Send 用（100% 濕）」。要讓好幾軌聽起來在同一個空間，就把殘響放在 **Bus** 上、濕度 100%，再由各軌的 Send 決定送多少。

## 立體聲寬度（Stereo Width）

單支麥克風錄的木吉他、人聲只有一個聲道，直接複製到左右還是「單聲道」。這個效果器會**自己生出左右不同的訊號**：

| 方式 | 適合 |
|---|---|
| Haas 延遲 | 單聲道來源。把訊號延遲 10–20 ms 放進一側，聽起來像用兩支麥克風錄的 |
| 相位去相關 | 單聲道來源。用全通濾波製造左右差異，沒有明顯的回聲，人聲、旁白更自然 |
| M-S 擴大 | 已經是立體聲的素材（取樣、MIDI 音源）。只把既有的左右差放大 |
| 全部混用 | 合成器、Pad，鋪滿整個音場 |

面板左邊是**立體聲向量示波器**：一條垂直線代表完全單聲道、橫向散開代表立體、貼近水平代表左右反相。右邊顯示**立體寬度**（側向能量／中央能量）與**左右相關度**（+1 完全相同、0 很寬、負值反相）。

設計上，側向訊號在左右是**相反相加**的，所以：

- 單聲道監聽（手機、車上喇叭、店裡音響）時寬度會消失，但**不會有相位問題**，原本的聲音完全保留
- 「低頻保持單聲道」會把指定頻率以下留在中央，低頻比較穩、不會左右亂飄

## 人聲和聲（Harmony）

在主唱軌加入 **Harmony 人聲和聲**（建議放在人聲修音後面、EQ／壓縮之前），點開面板：

1. **選部數**：上方「1 部～4 部」，或直接挑預設值（上三度、三度＋五度、上下三度、雙重人聲、高低八度、流行合唱 4 部）。
2. **每個聲部**可以選音程（上／下三度、四度、五度、六度、八度，或同度做雙重人聲）、音量與左右位置。
3. **和聲依據**：
   - **依調性**：選主音與音階（或按「🔍 偵測調性」），和聲會沿著音階走，例如 C 大調裡 E 的上三度是 G、A 的上三度是 C。
   - **依和弦**：選一條伴奏軌（鋼琴、吉他的 MIDI 或錄好的音訊），按「🎹 抓和弦」。程式會分析每 2 拍（可改成每拍或每小節）的和弦，畫在下方時間軸上。和聲只會落在和弦音上，最不容易出現不和諧的音。也可以按「用調性填滿」先放一排和弦，再自己改。
4. **修改和弦**：點時間軸「和弦」列上的方塊，下方會出現編輯列，可以改根音與性質（大三、小三、七和弦、掛留等）、從中間切開、併入下一個或刪除；拖曳右邊界改長度；在空白處拖曳新增。

### 即時 vs 高品質（預先運算）

面板最上方可以選和聲的產生方式：

| | ⚡ 即時 | ✨ 高品質（預先運算） |
|---|---|---|
| 邊唱邊聽 | 可以（開輸入監聽 I） | 不行 |
| 音準 | 一般（換音的頭幾十毫秒容易不穩） | 準確，聽起來乾淨 |
| 怎麼用 | 調整後馬上聽到 | 設定好後按「**運算和聲**」，每個聲部變成主唱下方的一條音訊軌 |

**高品質模式**會先把整段主唱分析完再產生和聲，可以看到前後的音，所以不會在某個母音突然抓錯八度、換音時也會跟著主唱平行滑過去。實測（含顫音、滑音、氣音與唱歪的測試人聲）：即時模式約有 10% 的時間會唱到錯的音、平均偏差約 14 cent；高品質模式錯音約 2%（幾乎都在換音的那一瞬間）、平均偏差約 6 cent（人耳很難分辨）。

- 算好的和聲軌叫「主唱 和聲 1（高品質）」等，在主唱軌正下方，可以各自調音量、聲像、加效果，也可以剪輯。
- 改了聲部、音程、調性、和弦、段落或片段位置之後，面板會顯示「**設定已變更**」，按「**重新運算**」更新。
- 「**保留顫音**」：100% 和聲的顫音跟主唱一模一樣（最像同一個人疊錄）；調低則和聲是比較平穩的長音。
- 主唱軌上 Harmony **前面**的效果器（例如人聲修音）會先套用，再拿去算和聲；所以先修音、再做和聲，和聲也會是修過的音準。
- 速度：一般電腦約是即時的 5～8 倍，3 分鐘的主唱每個聲部大約 30 秒。運算在背景進行，畫面不會卡住。
- 切回即時模式時會詢問是否刪除算好的和聲軌。

### 依段落切換和聲

勾選「**段落模式**」後，只有在時間軸「段落」列上的範圍裡才有和聲，每一段可以用不同的聲部與音程。例如主歌（第 1～8 小節）只用一部上三度，副歌（第 9～16 小節）四部全開。

- 在「段落」列空白處拖曳框出小節範圍；點一下段落，下方可以逐部選音程或「不唱」
- 不知道怎麼配？按「**🎲 自動編排**」：程式會依人聲的樂句與音量切段，越大聲的樂句分配越多聲部，並畫好每部的音量曲線。每按一次會換一種版本，滿意了再手動微調
- 每個聲部下方有一條**音量曲線**：點一下加控制點、拖曳移動、右鍵或雙擊刪除。可以做出副歌和聲漸強、句尾淡出

### 旋鈕

| 旋鈕 | 意思 |
|---|---|
| 主唱／和聲 | 主唱與和聲各自的音量（主唱調到最左可以只聽和聲，方便另外輸出） |
| 寬度 | 各聲部左右分開的程度 |
| 和聲音準 | 100% 和聲完全對準目標音；調低會跟著主唱原本的音準起伏，比較自然 |
| 人性化 | 每個聲部加入一點不同的時間差與音準飄移，聽起來像不同的人在唱；0% 是整齊的機械感 |
| 滑音 | 換音時和聲滑過去的時間 |

小提醒：

- 和聲只適合**單一旋律**的人聲（獨唱、清唱）。混了伴奏或殘響的音檔偵測會不穩，可以先用「人聲／伴奏分離」取出人聲。
- 即時模式的延遲約 32 毫秒，播放與輸出時會自動補償。
- 移調越多，聲音越不像原本的人：上下三度、五度最自然，八度會比較明顯。往上八度的聲部會稍微小聲一點，可以把該聲部的音量拉高 2～3 dB。
- 錄音時打開該軌的 **I（輸入監聽）**，可以邊唱邊聽和聲（只有即時模式；停止播放時使用聲部的基本設定，不看段落）。

## 升降音（轉調）

在音訊片段上按右鍵，選「**升降音…**」。可以一次選多個片段一起處理。

- 選要升降幾個半音（上排降、下排升），或輸入半音與微調（cent，100 cent = 1 個半音）
- **長度不變、只改音高**，用高品質演算法（WSOLA）重新計算整段音訊，音準準確
- 算好之後片段名稱會標上 ［+2］ 之類的記號；再移一次會累加，不會重複疊加
- 原本的音訊保留在復原紀錄裡，Ctrl+Z 就能回到原調
- 常見用途：伴奏降 1～2 個全音配合歌手音域；把 C 調的伴奏轉成 D 調

移調超過 ±5 個半音時，人聲會開始變尖或變悶，屬於正常現象；樂器伴奏比較能承受大幅移調。

## 人聲／伴奏分離

在音訊片段上按右鍵，選「**分離人聲／伴奏**」。會在下方新增兩條軌：人聲與伴奏。

這是**簡易版**：利用「主唱通常在正中央、伴奏分布在左右」的混音習慣，加上頻率範圍篩選來分離。

- **效果好**：主唱在正中央、伴奏有明顯左右分布的流行歌。適合做練唱伴奏、卡拉 OK。
- **效果有限**：單聲道錄音、現場錄音、人聲加了很重的立體聲殘響，或貝斯、大鼓也在正中央的曲子（這些會跟人聲一起被分到「人聲」，程式會用頻率篩選盡量排除）。
- 分離不會修改原本的片段，原片段會被靜音保留，可以隨時比較或刪除。

### AI 分離（Demucs）

想要更乾淨的分離，在片段上按右鍵選「**AI 分離人聲／伴奏（Demucs）…**」。這是**選用功能**，不用就不會下載任何東西。

1. 第一次使用：在對話框點「下載」，瀏覽器會把 `htdemucs_embedded.onnx`（約 172 MB）存到下載資料夾。下載由你的瀏覽器直接向 Hugging Face 進行，這個網頁本身沒有對外連線的權限。
2. 下載完成後把檔案拖進對話框（或按「選擇檔案…」）。網頁會核對檔案大小與 SHA-256，正確才使用，並存在瀏覽器裡，下次不用再選。
3. 選處理器、按「開始分離」。可以勾選「另外分出鼓、貝斯、其他樂器」，一次得到 4 個分軌。

模型是 Meta 的 **Demucs v4（htdemucs）**，MIT 授權，經 demucs-web 轉成瀏覽器可以執行的格式。

- **速度**：這個模型非常重。實測只用 CPU 約是音樂長度的 **15～20 倍**（3 分鐘的歌約 45～60 分鐘）；新版 Chrome／Edge 會優先用顯示卡（WebGPU），快多少要看顯示卡。建議先拿一小段（例如副歌 20 秒）試試看。如果顯示卡跑到一半出錯，會自動改用 CPU。
- **記憶體**：至少需要 2–4 GB 可用記憶體。太長的片段可以先切短再分離。
- 不想留著模型時，在對話框按「移除模型」即可。

## 母帶

按「母帶」（Shift+M）打開母帶面板。處理鏈的順序是：

**色調 EQ → 黏合壓縮 → 立體寬度 → Limiter**

左邊是響度表：

- **短期**：最近 3 秒的響度
- **整合**：從開始播放到現在的整體響度（串流平台看的就是這個）
- **Limiter**：正在壓掉多少分貝

### 一鍵最佳化

選目標後按「✨ 一鍵最佳化」，程式會離線分析整首歌，自動設定 EQ、壓縮與 Limiter，讓成品剛好落在目標響度，而且峰值不超過上限：

| 目標 | 響度 | True Peak 上限 |
|---|---|---|
| 串流平台（Spotify / YouTube） | −14 LUFS | −1 dBTP |
| Apple Music | −16 LUFS | −1 dBTP |
| Podcast／人聲節目 | −16 LUFS | −1.5 dBTP |
| CD／俱樂部（大聲） | −9 LUFS | −0.3 dBTP |
| 廣播電視（EBU R128） | −23 LUFS | −1 dBTP |

完成後會顯示前後數值；不滿意可以按 Ctrl+Z 復原。如果 Limiter 推得太多（超過 10 dB），面板會提醒你先把混音本身做大聲一點，效果會比較自然。

按「分析」可以得到整首的精確數值，包括 LRA（響度範圍）。

## 自動伴奏電子琴

按上方的「**伴奏**」打開。用法跟市面上的自動伴奏電子琴（編曲琴）一樣：**左手按和弦、右手彈旋律**，伴奏會依和弦自動演奏鼓、貝斯、鋼琴、吉他、弦樂、琶音六個聲部。

1. **選風格**：華語抒情（8 分鋼琴）、華語流行（中板 8 Beat）、校園民謠（木吉他）、流行搖滾、R&B／靈魂樂、6/8 抒情。換風格時速度會換成建議值，可以用 −／＋、輸入數字或連按 **TAP** 調整。
2. **按 START**（或 **SYNC**：按下第一個和弦才開始，跟著樂團一起進拍最方便）。
3. **左手按和弦**：分割點（預設 F♯3）以下是左手。和弦辨識有三種：
   - **多指**：照一般和弦按法（C、Am7、G/B、Csus4…都認得，轉位與分割和弦也可以）
   - **單指**：只按根音 = 大三和弦；根音加左邊任一黑鍵 = 小和弦；加左邊白鍵 = 七和弦；黑白都加 = 小七和弦
   - **整個鍵盤**：雙手按的音都拿來認和弦（右手照常發聲）
   勾「放開仍保持和弦」時，左手放開後伴奏繼續用剛剛的和弦。
4. **切換段落**：Intro 前奏、主歌 A、主歌 B、導歌 Pre、副歌 1、副歌 2、間奏／橋段、Break 停頓、Ending 尾奏。
   - 切換在**下一個小節線**生效，按鈕會閃黃燈表示「下一小節換過去」。勾「換段落時自動過門」時，這一小節剩下的部分會打過門（鼓的 Fill-in）。
   - 再按一次**目前的段落**（或 FILL）= 只打過門、不換段落。
   - **Intro 與 Ending 有自己的和弦進行**（依歌曲的調），左手不用按。前奏跑完自動進主歌 A；尾奏結束後自動停。
   - 主歌 A 最素（多半只有鋼琴＋貝斯），越往副歌 2 樂器越多、鼓越滿，就像華語流行歌的編曲層次。
5. **聲部**：每個聲部可以開關、換音色、調音量。六個聲部其實是專案裡的「伴奏-鼓／貝斯／鋼琴／吉他／弦樂／琶音」MIDI 軌，所以也能在混音台加效果。載入 SoundFont 後音色選單會多出「SoundFont：…」，按「GM」則會自動換成音色庫裡對應的鋼琴、鋼弦吉他、指彈貝斯、弦樂、鼓組。
   「**伴奏音量**」滑桿（預設 72%）調整整體力度：六個聲部全開時如果聽到破音，往左調就好。已經錄成 MIDI 片段的段落不受影響——錄下來的是當時的力度。
6. **● REC**：把伴奏錄成 MIDI 片段。專案速度會改成伴奏速度、DAW 從播放頭所在的小節開始播放，伴奏對齊小節線一起開始；錄完每個聲部都是一個 MIDI 片段，可以在鋼琴捲簾裡修改。右手旋律要錄的話，把「伴奏-鋼琴」或另一條 MIDI 軌設成待命（R）就會一起錄。

**用什麼彈**

- **滑鼠**：面板下方的 61 鍵鍵盤可以直接點、按住拖曳滑過去。淺藍色區域是左手（和弦區），按下的和弦音會亮綠色。
- **電腦鍵盤**：按 Caps Lock 開啟「鍵盤彈奏」（A S D F… 是琴鍵、Z／X 換八度）。面板開著時：數字 **1–9** 切換段落、**Enter** 啟動／停止、**Backspace** 同步啟動、**\** 過門、**− ＝** 調速度。
- **MIDI 鍵盤**：直接彈。按「**MIDI 鍵位設定**」可以把任何一個鍵、推桿或踏板（CC）對應到任何一個按鈕：按「學習」→ 在 MIDI 鍵盤上按那個鍵就設定好了，對應到的鍵不會發聲。「快速設定」會把最低音區（C1 起）依序設成前奏、主歌 A、主歌 B、導歌、副歌 1、副歌 2、間奏、尾奏、過門、啟動，適合 88 鍵的鍵盤。

## 專輯母帶（批次處理）

整張專輯一起處理：按上方的「**專輯**」。這個功能處理的是**已經混好的音檔**，跟目前的專案無關，可以一次放 20 首以上。

1. **加入歌曲**：把 WAV、FLAC、MP3、OGG、M4A 拖進清單，或按「加入檔案…」。會依檔名排序，拖曳 ⠿ 可以調整曲序；歌名可以直接改（就是輸出的檔名）。
2. **母帶**：
   - **每首一鍵最佳化**：每首歌各自分析，自動設定 EQ、壓縮與 Limiter（用歌曲最大聲的 60 秒找設定，再套用到整首）。
   - **套用目前專案的母帶設定**：每首都用「母帶」面板現在的設定。
   - **不處理**：只做淡入淡出與去靜音，聲音完全不變。
3. **目標響度**：串流平台 −14 LUFS、Apple Music −16 LUFS 等，跟母帶面板相同。
4. **專輯響度**：
   - **專輯模式（推薦）**：最大聲的那首到目標響度，其他歌保留一部分原本的差距。「保留差距」35% 的意思是：原本比最大聲那首小 12 LU 的抒情歌，處理後大約小 4 LU，聽整張專輯時有起伏、但不用一直調音量。
   - **每首都到目標響度**：每首一樣大聲，適合合輯或單曲。
5. **淡入淡出**：設定秒數與曲線（等功率、線性、指數、S 曲線），淡出有快速按鈕（1／2／3／5／8／10 秒）。清單裡每首歌也可以個別設定淡入、淡出（空白 = 用全域設定）。可以勾「第一首不淡入」。
6. **去掉頭尾的靜音**：低於設定音量（預設 −60 dB）的開頭與結尾會被裁掉，保留 30 毫秒，淡入淡出接在裁切之後。
7. 按「**開始處理**」，每首完成後清單會顯示處理前後的響度。按「原」「後」可以試聽比較，再按「⬇」下載單首或「下載全部」（可以打包成 ZIP，檔名可以加上 01_、02_ 曲序）。

**輸出格式跟原檔一樣**：取樣率、位元深度、MP3 位元率、單聲道／立體聲都不變。例如 MP3 192 kbps 進來就是 MP3 192 kbps 出去，WAV 24-bit 48 kHz 就是 WAV 24-bit 48 kHz。16／24-bit 會加 dither。

- VBR 的 MP3 會用最接近平均位元率的 CBR 輸出（會在清單上註明）。
- 瀏覽器沒有 OGG、M4A 的編碼器，這兩種會改輸出 FLAC（無損，不會比原檔差）。
- 每首約需要「歌曲長度的幾分之一」的時間；20 首一鍵最佳化大約幾分鐘。處理中請不要關閉分頁。

## 輸出

按「輸出」（Ctrl+E）：

| 選項 | 說明 |
|---|---|
| 整首混音／分軌 | 分軌會把每一軌各輸出一個檔案，打包成 zip，不受獨奏影響 |
| WAV | 無損，最通用；16／24／32-bit |
| FLAC | 無損，檔案比 WAV 小約 30–50% |
| MP3 | 有損，檔案最小；128–320 kbps，只支援 44.1／48 kHz |
| MIDI | 只包含 MIDI 軌的音符 |
| 影片 MP4 | H.264 + AAC，把時間軸上的影片、文字與字幕一起算成畫面（見下面「影片、文字與字幕」） |
| 範圍 | 整個專案，或只輸出循環區間 |

整首混音會依照目前的靜音／獨奏狀態，並套用母帶處理（若有開啟）。分軌預設**不**套用母帶，因為分軌通常是要交給別人混音的。節拍器的聲音不會被輸出。

## 影片、文字與字幕

在編排視窗左上角按 **＋影像**，可以匯入影片、新增文字軌或字幕軌。這三種軌道只出現在畫面上：**不進混音、輸出音檔時會被略過**，所以「只輸出音檔」跟「輸出 MP4」拿到的是同一份混音。

- **影片軌**：按「＋影像 → 匯入影片…」（或直接把影片拖進來）匯入 MP4 / WebM。片段跟音訊片段一樣可以拖曳、左右裁切；裁切只是改播放長度，原始檔不會被動到。影片檔存在瀏覽器裡，存檔時會一起放進 `.zyproj`。
- **文字軌／字幕軌**：在軌道上雙擊空白處新增一段文字，雙擊片段改文字內容。字幕預設在畫面下方、有半透明底；文字預設在上方、沒有底。
- **影片的聲音**：匯入時會自動把影片檔裡的聲音解出來，放進這一軌的音訊通道——軌道標頭上的音量、M（靜音）、S（獨奏）、效果器、母帶都照常作用，輸出 MP4 與輸出音檔都會包含它。標頭上的 <b>眼</b> 只隱藏畫面，聲音照樣播放；影片沒有音軌（或瀏覽器解不開）時就只有畫面。
- **預覽**（V）：打開 16:9 的預覽視窗，播放時跟著播放頭走。**直接用滑鼠在畫面上拖曳文字**就能改位置；下面的選單可以改畫布大小（含直式 1080×1920）與格率。
- **輸出 MP4**：輸出對話框選「影片 MP4」。聲音走跟輸出 WAV 完全相同的混音鏈（母帶、效果器都算進去），影像用瀏覽器內建的 H.264 編碼器逐格算圖，再封裝成 MP4。有影片的段落需要逐格定位，會比輸出音檔慢很多。

## 影像編輯：濾鏡、調色、轉場、淡入淡出

在影片片段上按兩下、或點一下影片／文字軌，**右側**就會打開影像面板（預設打開，分頁有）：

| 分頁 | 內容 |
|---|---|
| 濾鏡 | 10 種一鍵風格（黑白、暖陽、冷調、電影、復古、淡化、鮮豔、夜景、單色…），縮圖就是這一段畫面套上去的樣子；下方滑桿調強度 0–100% |
| 調色 | 亮度、對比、飽和、色溫、色調、暗角、褪色，範圍 −100～+100，「全部重設」一鍵回原樣 |
| 轉場 | 疊化、黑場、白閃、左／右／上／下滑、推移、縮放、模糊、圓形；只作用在**兩段相鄰影片的交界**，時長 0.2–2 秒，轉場記在前一段上（時間軸交界會出現一個 ⇄ 記號） |
| 淡入淡出 | 畫面的淡入／淡出秒數與淡出色（黑、白、米白）；文字與字幕也有自己的淡入淡出（透明度） |

- 所有效果都是**非破壞性**的：只記在片段上，原始影片檔不會被改，隨時可以復原（Ctrl+Z）。
- 預覽看到的結果跟輸出 MP4 完全一樣（同一段算圖程式）。
- 轉場需要「借用」前後片段的畫面，所以轉場時長不要超過任一段的長度；片段太短時會自動縮短。
- 畫面的淡入淡出跟聲音的淡入淡出是分開的：聲音請在時間軸拉片段兩端的小把手。

## 從「自動抓和弦」帶東西進來

「[自動抓和弦](/chord-detection/)」分析完一首歌之後：

- 按 **🎹 給編曲工具** 會下載 `.zychords.json`。回到這裡按 **檔案 → 匯入和弦…** 選它，整首歌的和弦就會畫在和弦軌上（每小節是什麼和弦、調性、拍數都在裡面）。如果速度跟目前專案不一樣，會問你要不要改成來源速度。
- 按 **⬇ 人聲／伴奏** 會下載兩個 WAV（AI 有分離主唱時才有）。把兩個檔案一起拖進編排視窗，它們會各自變成一軌、起點對齊。
- 拿到別人的分軌包（`.zip`，裡面是 wav/mp3）也可以直接丟進來：檔案 → 匯入音檔 → 選 zip，裡面每個音檔各放一軌、都從頭開始，直接就能混。

## 專案檔

- **儲存**（Ctrl+S）：Chrome / Edge 會直接存回同一個檔案；其他瀏覽器會下載一份新的。Ctrl+Shift+S 另存新檔。

- **開啟**（Ctrl+O）：選 `.zyproj`，或直接拖進編排視窗。
- `.zyproj` 其實是一個 zip，裡面是 `project.json`（專案設定）與 `audio/`（所有用到的音訊，32-bit 無損）。

## 常見問題

**按播放沒有聲音？**
瀏覽器規定要先點過網頁才能發聲，請先點一下畫面任何地方。也請確認沒有開到某一軌的獨奏（S），以及電腦的輸出裝置正確。

**MIDI 錄音時踩踏板，出現很多奇怪的音符？**
這是舊版的問題，已經修正：以前每放開一個音都會讓播放重新排程，踏板放開時一次結束很多音就會亂跳。現在錄音中不會重新排程，踏板也改成另外記錄。

**錄音對不上拍子？**
到狀態列按「校正」調整延遲補償。請不要用藍牙耳機錄音。

**修出來的音不對？**
先確認調性設對了（可以按「偵測調性」再聽聽看）。如果歌曲中途轉調，可以把歌切成兩段放在不同軌，各自設定。偶爾跳錯八度多半是音域選錯，改成符合歌手的音域試試。

**錄音時聽到很大的回音或嘯叫？**
你可能開了輸入監聽（I）又沒戴耳機，請戴耳機或關掉 I。

**專案不見了？**
重新打開網頁時會詢問是否還原暫存。如果清除過瀏覽資料，暫存會消失，所以重要的專案請一定要按「儲存」存成檔案。

**電腦變得很慢？**
很多軌同時掛殘響最吃資源，改用 Send 共用 Bus A 的殘響。也可以先把不用的效果器關掉。

**手機能用嗎？**
畫面可以打開，但這是為桌機設計的工具，手機上很難操作，錄音與 MIDI 功能也不一定可用。
