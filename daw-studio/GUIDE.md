# 織音線上編曲製作　使用說明

織音線上編曲製作是一套在瀏覽器裡執行的編曲軟體（DAW）。不用安裝、不用註冊，打開網頁就能錄音、編 MIDI、混音、做母帶，最後輸出成音檔。

[**▶ 開啟織音線上編曲製作**](../)

## 你的檔案不會離開電腦

這個頁面的安全政策（Content-Security-Policy）設定為 `connect-src 'self'`：瀏覽器會擋下這個頁面對**其他任何伺服器**發出的連線，只允許讀取本站自己的程式檔（AI 人聲分離的執行引擎）。本站是純靜態網站（GitHub Pages），沒有任何可以接收檔案的地方。所以不是「我們承諾不上傳」，而是**技術上就沒辦法上傳**。

- 錄音、匯入的音檔、MIDI、效果器設定，全部只在你的電腦上處理。
- 專案存成 `.zyproj` 檔，放在你自己選的資料夾。
- 瀏覽器會另外自動暫存一份（IndexedDB），關掉分頁再打開時可以還原。暫存只在這台電腦的這個瀏覽器裡，清除瀏覽資料就會消失，重要的專案請按「儲存」另存檔案。

## 畫面介紹

- **上方控制列**：新增／開啟／儲存專案、匯入音檔與 MIDI、播放控制、小節與時間顯示、速度（BPM）、拍號、節拍器、對齊格線，右側是各面板的開關與「輸出」。
- **左側檢閱器**：目前選取軌道的名稱、顏色、音色、插入效果器、Send，以及這一軌和 Master 的推桿。
- **中間編排視窗**：每一列是一條軌道。左邊是軌道標頭（M 靜音、S 獨奏、R 錄音待命、I 輸入監聽、音量），右邊是時間軸上的片段。
- **下方面板**：混音台、鋼琴捲簾、母帶，一次顯示一個。
- **配色**：控制列的「配色」按鈕可以切換「專業深色」（預設）、「世界聲音・木質深色」、「世界聲音・木質淺色」，後兩種和世界聲音網站同一套色票；選擇會記在這個瀏覽器裡。

左上角的「**首頁**」按鈕會回到世界聲音；專案已經自動暫存，回來時可以還原。

## 快速開始

### 用音檔做混音

1. 把音檔（WAV、MP3、FLAC、OGG、M4A）**拖進音訊軌**，或在空白處雙擊選檔。一次拖多個檔案會自動往下排到不同軌。
2. 按**空白鍵**播放。點上方尺規可以移動播放頭。
3. 按「混音台」調整每一軌的音量與左右位置。
4. 按「輸出」，選格式，檔案會直接下載到你的電腦。

### 錄音

1. 按某一條音訊軌的 **R**（錄音待命）。第一次會詢問麥克風權限。
2. 想一邊錄一邊聽自己的聲音，再按 **I**（輸入監聽，請戴耳機以免回授嘯叫）。
3. 需要預備拍就按上方的「1234」，錄音前會先響一小節節拍器。
4. 按紅色**錄音鍵**（或鍵盤 R）開始，再按一次或按停止結束。
5. 新錄的內容會蓋掉同一段時間裡的舊片段（punch-in）。

錄音自動扣掉瀏覽器回報的延遲。如果錄好的聲音總是比節拍晚一點，到下方狀態列按「校正」微調。

### 用 MIDI 編曲

1. 預設的第 13–16 軌是 MIDI 軌（鋼琴、弦樂、貝斯、鼓組），軌號旁邊有 ♪ 記號。
2. 在 MIDI 軌上**雙擊**，會建立一個 4 小節的空白片段並打開鋼琴捲簾。
3. 在鋼琴捲簾上**點一下**新增音符，拖曳可移動，拖右緣可改長度。
4. 在檢閱器的「音色」選單換樂器。

## 編輯片段

| 動作 | 方法 |
|---|---|
| 移動 | 拖曳片段 |
| 複製 | 按住 Alt 拖曳，或 Ctrl+D 接在後面 |
| 修剪頭尾 | 拖曳片段左右邊緣 |
| 淡入／淡出 | 拖曳片段上緣左右兩端的小圓點 |
| 切開 | 播放頭移到要切的位置，按 Ctrl+T |
| 框選多個 | 在空白處拖曳；Shift 加選 |
| 刪除 | Delete |
| 微調位置 | 方向鍵左右，一次移動一格格線 |
| 復原／重做 | Ctrl+Z ／ Ctrl+Shift+Z |

格線大小會跟著縮放自動切換（小節、拍、八分、十六分）。按 **G** 或上方「對齊」可以關閉吸附，自由擺放。

**循環播放**：在尺規最上緣拖出一段範圍，按 **C** 開關循環。

## MIDI

### 鋼琴捲簾

- **點空白**：新增音符（長度沿用你上一次調的長度）
- **拖曳音符**：移動；**拖右緣**：改長度；**Alt 拖曳**：複製
- **Shift 拖曳空白處**：框選
- **右鍵**音符：刪除
- 下方力度條：拖曳調整音符力度
- 工具列：格線（1/4 到 1/32、三連音）、**量化**（Q）、移調（↑↓，Shift 為八度）

鼓組軌的左側琴鍵會顯示 GM 鼓位名稱（大鼓、小鼓、閉合鈸……），直接點對應那一排即可。

### 彈奏與錄 MIDI

- **MIDI 鍵盤**：插上就能用（Chrome / Edge）。上方的小圓燈有訊號時會閃。
- **電腦鍵盤彈奏**：按 **Caps Lock** 開關。A S D F G H J K L 是白鍵，W E T Y U O P 是黑鍵，Z / X 換八度，C / V 調力度。
- **錄 MIDI**：按 MIDI 軌的 R，再按錄音鍵，邊彈邊錄成新的 MIDI 片段。
- **延音踏板**：接在 MIDI 鍵盤上的踏板（CC64）會被錄下來。音符長度記錄的是「手實際按住的長度」，踏板另外記在鋼琴捲簾下方的「踏板」列，播放時再把延音套上去——所以鋼琴捲簾不會被踏板拉成一大片重疊的長條。踏板列可以直接編輯：點空白新增一段、拖兩端改長度、右鍵刪除。匯出／匯入 .mid 時踏板也會一起保留。
- **輸入移調**：上方的「− 0 ＋」可以讓鍵盤彈的音整體升降（±24 半音），錄進去的就是移調後的音。快捷鍵 `[` `]` 一次半音、`Shift+[` `Shift+]` 一次八度，雙擊數字歸零。

### 匯入／匯出 .mid

上方「匯入 MIDI」或直接把 .mid 拖進編排視窗，每一軌會變成一條 MIDI 軌，並依原本的樂器編號挑選接近的音色。專案還是空的時候，會採用 MIDI 檔的速度與拍號。在「輸出」選 MIDI 格式，或在片段上按右鍵「匯出成 .mid」。

### 改速度

MIDI 片段以拍數記錄，改 BPM 時會跟著小節走。音訊片段的起點也會移到同一個小節位置，但音訊本身不會被加速或減速。

## 音色

### 內建音色

不需要下載：平台鋼琴、電鋼琴、管風琴、弦樂合奏、弦樂撥奏、溫暖 Pad、方波 Lead、合成撥弦、合成貝斯、指彈電貝斯、鐘琴、木琴，以及 GM 鼓組。

### SoundFont 音色庫

想要更真實的樂器聲，可以載入 SoundFont（.sf2）。按上方「**音色庫**」：

1. **下載**：對話框裡列了三套免費音色庫，按「下載」就會從官方來源下載到你的電腦。最推薦先用 **GeneralUser GS**（31 MB）。
2. **自動載入**（Chrome / Edge）：按「設定下載資料夾」選一次你的「下載」資料夾。之後下載完成、切回這個分頁，就會自動找到並載入。網頁只讀取資料夾裡的 .sf2，不會上傳或修改任何檔案。重新打開網頁後，瀏覽器可能要你再按一次「允許讀取」。
3. **手動載入**：也可以直接把 .sf2 拖進對話框。

載入後的音色庫會記在這個瀏覽器裡，下次打開不用重選。到 MIDI 軌的檢閱器「SoundFont 音色」選單挑選樂器。

> 不支援 .sf3（壓縮格式），請下載同一套音色庫的 .sf2 版本。專案檔只記錄你用了哪一套音色庫，不會把音色庫打包進去；在別台電腦開啟時，要先載入同一套音色庫，否則會用內建音色代替。

## 效果器

每一軌可以掛 6 個**插入效果器**：在檢閱器或混音台點「＋」新增，點一下效果器名稱打開參數面板。每個效果器都有**預設值選單**，挑一個最接近的再微調最快。

| 效果器 | 用途 |
|---|---|
| **Auto Tune 人聲修音** | 依調性把唱歪的音拉準；可以很自然，也可以做出機械感的電子人聲。詳見下方「人聲修音」。 |
| **Harmony 人聲和聲** | 從一條主唱即時產生 1～4 部和聲，可以依調性或依伴奏的和弦，也能依小節切換不同的和聲。詳見下方「人聲和聲」。 |
| **EQ 等化器** | 8 段參數 EQ。曲線上的圓點可以直接拖曳（左右改頻率、上下改增益，滾輪改 Q 值），播放時背景會即時顯示頻譜。預設值有人聲、木吉他、鼓組、貝斯、溫暖、明亮、電話音效等。 |
| **Compressor 壓縮器** | 控制動態，讓忽大忽小的聲音變平均。預設值有人聲、鼓組、貝斯、溫和平衡、強力壓縮等，面板會即時顯示壓縮量。 |
| **De-esser 去齒音器** | 只壓「ㄙ、ㄘ、ㄕ」這類尖銳的齒音（約 4–10 kHz），其他頻率不受影響。可以開「只聽被壓的部分」找出齒音在哪。 |
| **Saturation 飽和度** | 磁帶、真空管、電晶體、硬削波四種特性，從溫暖的微失真到明顯破音。 |
| **Reverb 殘響** | 六種空間（房間、大廳、板式、教堂、彈簧、閘門）＋早期反射、調變與立體寬度。面板左邊畫空間剖面、右邊畫低頻／高頻兩條衰減曲線，依樂器分類的預設值有 9 組。詳見下方「殘響」。 |
| **Stereo Width 立體聲寬度** | 把單聲道來源（木吉他、單支麥克風的人聲、貝斯）變成有寬度的立體聲，也可以把既有的立體聲再拉寬。面板上有立體聲向量示波器與相關度表。詳見下方「立體聲寬度」。 |
| **Delay 延遲** | 回聲，時間以拍為單位，會跟著 BPM；可開左右彈跳。 |
| **Chorus 合唱** | 讓聲音變寬、變厚。 |
| **Distortion 失真** | 比較兇的破音。 |
| **Noise Gate 噪音閘** | 安靜時把底噪關掉。只在即時播放時作用，輸出檔案時會略過。 |
| **Pitch 即時移調** | 做和聲、八度疊加、雙重人聲等效果（附預設值）。即時運算，音準會有輕微顫動；要把整段轉調請用下方的「片段升降音」。 |

效果器槽的 ● 可以暫時關閉（bypass）；右鍵可以調整順序或移除。

效果器面板可以**同時開好幾個**（例如一邊看 EQ、一邊調壓縮），新開的面板會錯開排列；點一下面板就會移到最上層，拖曳標題列可以移動。按 **Esc** 關掉最上面那一個。

### Send 匯流排

多條軌道共用同一個殘響，聽起來會在同一個空間裡，也比較省電腦資源。檢閱器的「Send」可以把每一軌送到：

- **Bus A 殘響**
- **Bus B 延遲**

匯流排本身的效果器與音量在混音台最右邊調整。

## 混音台

按「混音台」（X）。每一軌有效果器槽、Send A／B 小旋鈕、聲像、推桿、立體聲電平表、峰值與 M／S／R。峰值超過 0 dB 會變紅，點一下可以重設。

推桿與旋鈕：**雙擊**回到預設值，**Shift 拖曳**微調。

## 自動化

按「自動化」（A），每條軌道會顯示一條曲線：

- 在軌道標頭的選單選要自動化的參數：音量、聲像、Send A、Send B
- **點曲線**新增控制點，**拖曳**移動，**雙擊**或右鍵刪除
- 拖曳時按住 Shift 可以不吸附格線
- 標頭的黃色 **R** 是「讀取自動化」開關；關掉時用推桿的固定值

## 人聲修音（Auto Tune）

在人聲軌的效果器第一格加入 **Auto Tune**，點開面板：

1. **設定調性**：選「主音」和「音階」，或按「🔍 偵測調性」讓程式分析這一軌（還沒錄音時會參考整首的 MIDI 軌）。也可以直接點面板右邊的小鍵盤，把某個音加入或排除（會變成「自訂」音階）。
2. **挑預設值**：一般唱歌建議用「**自然修音（推薦）**」，聽不太出處理痕跡；想要電子人聲效果就選「**機械音（T-Pain）**」。
3. **微調旋鈕**（拖曳上下、滾輪微調、雙擊回到預設）：

| 旋鈕 | 意思 |
|---|---|
| 修正速度 | 偏掉的音多快被拉回來。0 ms 是瞬間跳到（機械音）；40–70 ms 自然；100 ms 以上只修長音，保留滑音 |
| 修正強度 | 100% 拉到完全準；調低只修一部分，保留一點人味 |
| 保留顫音 | 只修正音高中心，保留原本的抖音。調低會把顫音拉平 |
| 濕度 | 混入多少原聲 |

「音域」選單可以配合歌手（男低音、女高音），偵測會更穩；樂器（例如小提琴、薩克斯風）選「樂器」。

面板上方左邊是**調音表**：指針在中間（綠色）代表唱得準，偏左是偏低、偏右是偏高。右邊的**音高曲線**同時畫出原本唱的（灰色）和修正後的（彩色），橫線是目前音階裡的音。

**邊唱邊聽修正後的聲音**：按下該軌的 **R** 和 **I**，戴耳機唱，耳機裡就會是修過的聲音。錄進去的仍是**原聲**，之後可以隨時改調性或設定，不必重錄。

**延遲**：修音需要約 32 毫秒分析音高。播放與輸出時會自動補償，跟伴奏完全對齊；只有錄音時的耳機監聽會晚約 32 毫秒，一般唱歌不太會察覺。

### 現場低延遲（16 ms）

面板中間有一顆「**現場低延遲**」開關，也有人用「現場演出（低延遲）」預設值。開啟後分析窗縮短一半，耳機監聽的延遲降到約 **16 毫秒**，邊唱邊聽幾乎沒有回音感；代價是最低音域只到 **100 Hz**（一般人的低音都在這之上，男低音最低的幾個音可能受影響），修正速度太快時也比較容易聽出機械感。錄音、排練、直播用現場模式；正式混音再切回標準模式。

### 音符編輯：一個音一個音指定

按「**分析這一軌**」，程式會把這一軌的錄音切成一顆一顆的音符，畫成下面的鋼琴捲簾（藍色＝原本的音、粉紅＝你改過音高的音）。之後：

- **拖曳音符**：上下改音高、左右改時間
- **拖曳右緣**：改音符長度
- **滾輪**：微調音高（每次 0.1 個半音）
- **右鍵**：刪除這個音
- 選一個音之後，下面的「音高」「強度」滑桿可以精準設定：音高以半音為單位（相對你唱的音），強度 0% 等於放掉這個音、讓它回到依音階自動修正

編輯過的地方會**蓋掉音階規則**：例如某一句想唱藍調的降五度，把那個音拉到該音高、強度 100%，它就會被修到那個音，而不是被拉回音階音。音符的時間是跟著**專案時間軸**跑的，所以改了片段位置要重新分析一次。

小提醒：

- 修音只能修「單一旋律」，和聲、合唱、吉他和弦這類同時有多個音的聲音不適合。
- 先修音、再 EQ／壓縮／殘響；殘響放在修音前面會讓音高偵測不穩。
- 子音、氣音、無聲段落不會被處理，原樣通過。

## 殘響（Reverb）

殘響面板分三塊：上面是**空間類型**，中間是**圖**，下面是參數。

| 空間 | 聽起來 |
|---|---|
| 房間 Room | 反射近、密、乾淨，尾巴短 |
| 大廳 Hall | 尾巴慢慢堆起來，最通用 |
| 板式 Plate | 沒有離散的反射、一瞬間就是密的尾巴，人聲與小鼓常用 |
| 教堂 Cathedral | 建立得慢、反射稀疏、尾巴最長 |
| 彈簧 Spring | 金屬共振的「啾」聲，復古吉他音箱的味道 |
| 閘門 Gate | 尾巴到固定時間就被切掉，80 年代小鼓的經典聲音 |

中間的圖：左邊是**空間剖面**（綠色是音源、藍色是聽者，黃線是第一次反射，虛線是預延遲）；右邊是**衰減曲線**，綠色是低頻、藍色是高頻——兩條分得越開，「高頻衰減」就越明顯。閘門類型的紅色虛線就是尾巴被切掉的位置。

參數：尾巴長度、預延遲、高頻衰減、**早期反射**（牆面反射的量）、**調變**（尾巴微微飄動，板式與大廳的「活」感）、**立體寬度**、濕度。

**依樂器挑預設值**：人聲板式／大廳、木吉他小房間、鋼琴大廳、弦樂教堂、鼓房間／閘門、彈簧殘響、以及「Send 用（100% 濕）」。要讓好幾軌聽起來在同一個空間，就把殘響放在 **Bus** 上、濕度 100%，再由各軌的 Send 決定送多少。

## 立體聲寬度（Stereo Width）

單支麥克風錄的木吉他、人聲只有一個聲道，直接複製到左右還是「單聲道」。這個效果器會**自己生出左右不同的訊號**：

| 方式 | 適合 |
|---|---|
| Haas 延遲 | 單聲道來源。把訊號延遲 10–20 ms 放進一側，聽起來像用兩支麥克風錄的 |
| 相位去相關 | 單聲道來源。用全通濾波製造左右差異，沒有明顯的回聲，人聲、旁白更自然 |
| M-S 擴大 | 已經是立體聲的素材（取樣、MIDI 音源）。只把既有的左右差放大 |
| 全部混用 | 合成器、Pad，鋪滿整個音場 |

面板左邊是**立體聲向量示波器**：一條垂直線代表完全單聲道、橫向散開代表立體、貼近水平代表左右反相。右邊顯示**立體寬度**（側向能量／中央能量）與**左右相關度**（+1 完全相同、0 很寬、負值反相）。

設計上，側向訊號在左右是**相反相加**的，所以：

- 單聲道監聽（手機、車上喇叭、店裡音響）時寬度會消失，但**不會有相位問題**，原本的聲音完全保留
- 「低頻保持單聲道」會把指定頻率以下留在中央，低頻比較穩、不會左右亂飄

## 人聲和聲（Harmony）

在主唱軌加入 **Harmony 人聲和聲**（建議放在 Auto Tune 後面、EQ／壓縮之前），點開面板：

1. **選部數**：上方「1 部～4 部」，或直接挑預設值（上三度、三度＋五度、上下三度、雙重人聲、高低八度、流行合唱 4 部）。
2. **每個聲部**可以選音程（上／下三度、四度、五度、六度、八度，或同度做雙重人聲）、音量與左右位置。
3. **和聲依據**：
   - **依調性**：選主音與音階（或按「🔍 偵測調性」），和聲會沿著音階走，例如 C 大調裡 E 的上三度是 G、A 的上三度是 C。
   - **依和弦**：選一條伴奏軌（鋼琴、吉他的 MIDI 或錄好的音訊），按「🎹 抓和弦」。程式會分析每 2 拍（可改成每拍或每小節）的和弦，畫在下方時間軸上。和聲只會落在和弦音上，最不容易出現不和諧的音。也可以按「用調性填滿」先放一排和弦，再自己改。
4. **修改和弦**：點時間軸「和弦」列上的方塊，下方會出現編輯列，可以改根音與性質（大三、小三、七和弦、掛留等）、從中間切開、併入下一個或刪除；拖曳右邊界改長度；在空白處拖曳新增。

### 依段落切換和聲

勾選「**段落模式**」後，只有在時間軸「段落」列上的範圍裡才有和聲，每一段可以用不同的聲部與音程。例如主歌（第 1～8 小節）只用一部上三度，副歌（第 9～16 小節）四部全開。

- 在「段落」列空白處拖曳框出小節範圍；點一下段落，下方可以逐部選音程或「不唱」
- 不知道怎麼配？按「**🎲 自動編排**」：程式會依人聲的樂句與音量切段，越大聲的樂句分配越多聲部，並畫好每部的音量曲線。每按一次會換一種版本，滿意了再手動微調
- 每個聲部下方有一條**音量曲線**：點一下加控制點、拖曳移動、右鍵或雙擊刪除。可以做出副歌和聲漸強、句尾淡出

### 旋鈕

| 旋鈕 | 意思 |
|---|---|
| 主唱／和聲 | 主唱與和聲各自的音量（主唱調到最左可以只聽和聲，方便另外輸出） |
| 寬度 | 各聲部左右分開的程度 |
| 和聲音準 | 100% 和聲完全對準目標音；調低會跟著主唱原本的音準起伏，比較自然 |
| 人性化 | 每個聲部加入一點不同的時間差與音準飄移，聽起來像不同的人在唱；0% 是整齊的機械感 |
| 滑音 | 換音時和聲滑過去的時間 |

小提醒：

- 和聲只適合**單一旋律**的人聲（獨唱、清唱）。混了伴奏或殘響的音檔偵測會不穩，可以先用「人聲／伴奏分離」取出人聲。
- 和聲用的是與 Auto Tune 相同的音高偵測，延遲約 32 毫秒，播放與輸出時會自動補償。
- 移調越多，聲音越不像原本的人：上下三度、五度最自然，八度會比較明顯。往上八度的聲部會稍微小聲一點，可以把該聲部的音量拉高 2～3 dB。
- 錄音時打開該軌的 **I（輸入監聽）**，可以邊唱邊聽和聲（停止播放時使用聲部的基本設定，不看段落）。

## 升降音（轉調）

在音訊片段上按右鍵，選「**升降音…**」。可以一次選多個片段一起處理。

- 選要升降幾個半音（上排降、下排升），或輸入半音與微調（cent，100 cent = 1 個半音）
- **長度不變、只改音高**，用高品質演算法（WSOLA）重新計算整段音訊，音準準確
- 算好之後片段名稱會標上 ［+2］ 之類的記號；再移一次會累加，不會重複疊加
- 原本的音訊保留在復原紀錄裡，Ctrl+Z 就能回到原調
- 常見用途：伴奏降 1～2 個全音配合歌手音域；把 C 調的伴奏轉成 D 調

移調超過 ±5 個半音時，人聲會開始變尖或變悶，屬於正常現象；樂器伴奏比較能承受大幅移調。

## 人聲／伴奏分離

在音訊片段上按右鍵，選「**分離人聲／伴奏**」。會在下方新增兩條軌：人聲與伴奏。

這是**簡易版**：利用「主唱通常在正中央、伴奏分布在左右」的混音習慣，加上頻率範圍篩選來分離。

- **效果好**：主唱在正中央、伴奏有明顯左右分布的流行歌。適合做練唱伴奏、卡拉 OK。
- **效果有限**：單聲道錄音、現場錄音、人聲加了很重的立體聲殘響，或貝斯、大鼓也在正中央的曲子（這些會跟人聲一起被分到「人聲」，程式會用頻率篩選盡量排除）。
- 分離不會修改原本的片段，原片段會被靜音保留，可以隨時比較或刪除。

### AI 分離（Demucs）

想要更乾淨的分離，在片段上按右鍵選「**AI 分離人聲／伴奏（Demucs）…**」。這是**選用功能**，不用就不會下載任何東西。

1. 第一次使用：在對話框點「下載」，瀏覽器會把 `htdemucs_embedded.onnx`（約 172 MB）存到下載資料夾。下載由你的瀏覽器直接向 Hugging Face 進行，這個網頁本身沒有對外連線的權限。
2. 下載完成後把檔案拖進對話框（或按「選擇檔案…」）。網頁會核對檔案大小與 SHA-256，正確才使用，並存在瀏覽器裡，下次不用再選。
3. 選處理器、按「開始分離」。可以勾選「另外分出鼓、貝斯、其他樂器」，一次得到 4 個分軌。

模型是 Meta 的 **Demucs v4（htdemucs）**，MIT 授權，經 demucs-web 轉成瀏覽器可以執行的格式。

- **速度**：這個模型非常重。實測只用 CPU 約是音樂長度的 **15～20 倍**（3 分鐘的歌約 45～60 分鐘）；新版 Chrome／Edge 會優先用顯示卡（WebGPU），快多少要看顯示卡。建議先拿一小段（例如副歌 20 秒）試試看。如果顯示卡跑到一半出錯，會自動改用 CPU。
- **記憶體**：至少需要 2–4 GB 可用記憶體。太長的片段可以先切短再分離。
- 不想留著模型時，在對話框按「移除模型」即可。

## 母帶

按「母帶」（Shift+M）打開母帶面板。處理鏈的順序是：

**色調 EQ → 黏合壓縮 → 立體寬度 → Limiter**

左邊是響度表：

- **短期**：最近 3 秒的響度
- **整合**：從開始播放到現在的整體響度（串流平台看的就是這個）
- **Limiter**：正在壓掉多少分貝

### 一鍵最佳化

選目標後按「✨ 一鍵最佳化」，程式會離線分析整首歌，自動設定 EQ、壓縮與 Limiter，讓成品剛好落在目標響度，而且峰值不超過上限：

| 目標 | 響度 | True Peak 上限 |
|---|---|---|
| 串流平台（Spotify / YouTube） | −14 LUFS | −1 dBTP |
| Apple Music | −16 LUFS | −1 dBTP |
| Podcast／人聲節目 | −16 LUFS | −1.5 dBTP |
| CD／俱樂部（大聲） | −9 LUFS | −0.3 dBTP |
| 廣播電視（EBU R128） | −23 LUFS | −1 dBTP |

完成後會顯示前後數值；不滿意可以按 Ctrl+Z 復原。如果 Limiter 推得太多（超過 10 dB），面板會提醒你先把混音本身做大聲一點，效果會比較自然。

按「分析」可以得到整首的精確數值，包括 LRA（響度範圍）。

## 輸出

按「輸出」（Ctrl+E）：

| 選項 | 說明 |
|---|---|
| 整首混音／分軌 | 分軌會把每一軌各輸出一個檔案，打包成 zip，不受獨奏影響 |
| WAV | 無損，最通用；16／24／32-bit |
| FLAC | 無損，檔案比 WAV 小約 30–50% |
| MP3 | 有損，檔案最小；128–320 kbps，只支援 44.1／48 kHz |
| MIDI | 只包含 MIDI 軌的音符 |
| 範圍 | 整個專案，或只輸出循環區間 |

整首混音會依照目前的靜音／獨奏狀態，並套用母帶處理（若有開啟）。分軌預設**不**套用母帶，因為分軌通常是要交給別人混音的。節拍器的聲音不會被輸出。

## 專案檔

- **儲存**（Ctrl+S）：Chrome / Edge 會直接存回同一個檔案；其他瀏覽器會下載一份新的。Ctrl+Shift+S 另存新檔。
- **開啟**（Ctrl+O）：選 `.zyproj`，或直接拖進編排視窗。
- `.zyproj` 其實是一個 zip，裡面是 `project.json`（專案設定）與 `audio/`（所有用到的音訊，32-bit 無損）。

## 常見問題

**按播放沒有聲音？**
瀏覽器規定要先點過網頁才能發聲，請先點一下畫面任何地方。也請確認沒有開到某一軌的獨奏（S），以及電腦的輸出裝置正確。

**MIDI 錄音時踩踏板，出現很多奇怪的音符？**
這是舊版的問題，已經修正：以前每放開一個音都會讓播放重新排程，踏板放開時一次結束很多音就會亂跳。現在錄音中不會重新排程，踏板也改成另外記錄。

**錄音對不上拍子？**
到狀態列按「校正」調整延遲補償。請不要用藍牙耳機錄音。

**Auto Tune 修出來的音不對？**
先確認調性設對了（可以按「偵測調性」再聽聽看）。如果歌曲中途轉調，可以把歌切成兩段放在不同軌，各自設定。偶爾跳錯八度多半是音域選錯，改成符合歌手的音域試試。

**錄音時聽到很大的回音或嘯叫？**
你可能開了輸入監聽（I）又沒戴耳機，請戴耳機或關掉 I。

**專案不見了？**
重新打開網頁時會詢問是否還原暫存。如果清除過瀏覽資料，暫存會消失，所以重要的專案請一定要按「儲存」存成檔案。

**電腦變得很慢？**
很多軌同時掛殘響最吃資源，改用 Send 共用 Bus A 的殘響。也可以先把不用的效果器關掉。

**手機能用嗎？**
畫面可以打開，但這是為桌機設計的工具，手機上很難操作，錄音與 MIDI 功能也不一定可用。
